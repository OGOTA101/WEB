# 🚗 ピクセル人生ゲーム DX (Pixel Jinsei Game DX)

市販の家庭用ボード版「人生ゲーム」のゲーム構造・イベント密度を徹底的に参考に、**完全ドット絵（低解像度クリーンピクセルアート）** で構築した、最大6人対応のオンライン＆CPUボードゲームです。

## ✨ 主な特徴

1. **完全ドット絵テイスト＆統一UI**
   - 6色の自動車コマ（自分ピン・配偶者ピン・子どもピンが実際に車の上に乗る仕様）、8種のアバター顔、25種以上の16×16ドットアイコン、10種のマイホーム建築、イベント発生時の64×36ドット絵カットインシーンまですべて滲みのないクリーンなピクセルアートで描画しています。
   - 8bit/16bit チップチューンBGM＆効果音シンセサイザー（Web Audio API）を内蔵しています。

2. **マス目のイベントがいつでもはっきり見える盤面設計**
   - ボード上の全108マスが大型のドット絵看板タイルとして描かれており、**各マスに番号・ドット絵アイコン・イベント名・金額/効果**が直接表示されます。
   - マス目にマウスカーソルを合わせる（またはクリックする）だけで、右上の**「🔍 マス目イベント詳細インスペクター」**にドット絵シーン・イベント全文・現在の手番プレイヤーから**「あと何マスで止まれるか」**がリアルタイム表示されます。
   - 上部の **「📖 全108マス図鑑」** ボタンから全チャプターのマスを一覧確認し、クリックでそのマスへカメラ移動することも可能です。

3. **「ルーレット (1〜10)」と「ダイス (1D6 / 2D6)」の両搭載**
   - **標準ルーレット (1〜10)**：通常の移動や10万ドル大抽選会で使用します。
   - **精密ダイス (1〜6) ＆ ダブルダイス (2〜12)**：初期配布および道中で手に入る「ダイス切替チケット」を使うことで、「あと数マス先の結婚・家購入・給料日・お宝マスに狙って止まりたい」「目の前のトラブルマスを飛び越えたい」といった場面でサイコロ移動に切り替えられます。
   - **ダイス専用イベントマス (`🎲`)**：新人研修ダイス、学園祭ダイス、ボウリング大会、年末ジャンボ宝くじ抽選（ゾロ目で+$50,000！）、カジノ丁半ダイス、海底遺跡発掘、大感謝祭ダイス、運命の10万ドルダイスなど、イベント内でもサイコロを振る機会が豊富にあります。

4. **家庭用ボード版と同等の長さと充実の人生イベント（全108マス＋4大分岐）**
   - **第1章**：人生スタート ＆ **進路選択分岐**（ビジネス就職コース vs 専門大学進学コース）
   - **第2章**：新社会人・初給料日・昇進チャンス ＆ **全員ストップ結婚式**（配偶者ピン乗車＆ご祝儀ダイス徴収）
   - **第3章**：出産・双子誕生・**マイホーム購入ストップ** ＆ **中盤ルート分岐**（ファミリー＆堅実街道 vs ベンチャー＆カジノ街道）
   - **第4章**：エリートスカウト転職 ＆ **第3分岐**（世界一周バカンスコース vs エリート本社出世コース）
   - **第5章**：別荘・豪邸買い替え、世界株バブル、ライバルからの資産奪取（仕返しマス）
   - **第6章**：**決算日ゲートストップ**（子ども1人につき$30,000の仕送り精算＆約束手形返済）＆ **最終分岐**（堅実ウィニングロード vs 一発逆転ギャンブル渓谷）〜 **ゴール「億万長者の館」**！

5. **借金（約束手形）・保険証券・株券・職業連動報酬**
   - **約束手形（借金）**：支払いで現金が足りなくなると自動的に1枚 `$20,000` の約束手形を借り入れます。「🏦 銀行・手形・保険」窓口からいつでも手動借入・返済が可能です。
   - **保険証券（3種）**：自動車保険・火災住宅保険・生命医療保険に加入しておくと、対応する事故・火災・病気マスの支払いが0円になり、見舞金を受け取れます。
   - **全21種の職業＋ランクアップ昇進＋他プレイヤー連動報酬**：医師・弁護士・料理人・建築士・アイドル・パイロット・アスリート・科学者などに就いていると、他のプレイヤーが関連マスに止まった際に報酬が支払われます。

6. **最大6人のオンライン通信対戦 ＆ ソロCPU対戦**
   - **ソロ＆CPU対戦**：人間1人＋CPU 1〜5人（最大6人）、または1台のPCでの複数人プレイに対応。
   - **オンライン通信対戦**：6文字のルームコードを発行・共有することで、WebRTC (PeerJS) ＋ BroadcastChannel ハイブリッド通信により最大6人（空き枠へのCPU追加も可）でリアルタイム対戦が楽しめます。
