# LINE SHOOTING: Neon Rift 仕様書

## コンセプト

縦長 9:16 画面で遊ぶ、協力対応のライン突破型アクションシューティング。プレイヤーは 16 x 30 の薄いグリッド上を 1 マス単位で移動し、上方向へ進み続ける。最上段を越えると同じラインの下側へワープし、スコアが 1 増える。スコア 5 ごとにボスが出現し、ガチャチケットを 1 枚得る。

## 画面とグリッド

- 画面比率: 9:16。
- グリッド: 横 16 マス、縦 30 マス。
- 両端 1 マスは通行不可。プレイヤーは 1-14 列を移動する。
- 下 2 マスは UI 領域。プレイヤーの移動可能範囲は 0-27 行。
- 縦ラインは読みやすく、横ラインは薄く描画する。
- SF ネオン表現。機体はキューブ型。敵は赤系統、味方は赤以外の色を中心に表示する。

## 操作

- タップした位置を仮想パッドの原点にする。
- 原点から上下左右へ倒すと、その方向へ 1 マスずつ連続移動する。
- 移動はマス単位だが、見た目は滑らかにスライドする。
- ダブルタップで特殊機能を発動する。
- スワイプして離すと、その方向へ回避する。
- 特殊機能と回避は時間経過で再使用可能。
- PC 向け補助操作: WASD / 矢印で移動、Space / X で特殊、Z で回避。

## 戦闘ルール

- スコアは画面奥へ到達した時だけ増える。
- 基本的に一撃死。船体パーツで HP が増える。
- HP が 0 になると DOWN 状態になる。
- DOWN 中でも復帰ゲージを保持し、味方の弾を受けるとゲージが溜まる。
- 復帰ゲージが 100 になると復帰する。
- ソロでは DOWN した時点でゲームオーバー。
- マルチでは全員 DOWN でゲームオーバー。
- 味方が敵弾に当たると、その敵弾は消える。他プレイヤーへ貫通しない。
- 味方が盾になるプレイを可能にする。
- 敵に接触するとダメージ。ボスの横を強引に抜けて突破することも可能。

## 射撃

- 主砲: 停止中だけ発射する弱攻撃。
- 副砲: 停止後、装備ごとの構え時間を経て発射する強攻撃。
- 主砲パターン: 単発、3ライン、レール、ビット追従。
- 副砲パターン: 高威力弾、レーザー、扇状弾、重い圧縮弾。
- 艦橋パーツで連射補正、ドローン追加、復帰補助、敵弾鈍化を付与する。

## 敵

- 通常敵は上から降りてくる。
- 強い敵だけが上側に滞在する。
- 通常敵は赤系統で統一。
- ドローン: 低 HP の基本敵。
- チャージャー: 少し横に揺れながら降りる敵。
- タレット: 上側に滞在して狙撃する強敵。
- ボス: スコア 5 ごとに出現。上側に滞在し、誘導弾、全ライン攻撃、拡散弾を使う。

## 機体カスタム

5 部位を編成できる。

- 主砲: 停止中の基本攻撃を決める。
- 副砲: 停止後の構え時間と強攻撃を決める。
- 機関: 速度 1-5、回避距離、回避クールダウンを決める。
- 船体: HP と特殊機能を決める。
- 艦橋: 追加機能を決める。

編成したパーツは機体の見た目に反映される。マルチプレイでは他プレイヤーのパーツ構成も同期され、半透明で表示される。

## ガチャ

- スコア 5 ごとにチケットを 1 枚得る。
- チケット 1 枚でパーツガチャを 1 回引ける。
- レアリティ: N / R / SR / UR。
- 重複パーツはチケットへ還元される。
- 所持パーツは一覧画面で確認でき、編成画面で装備できる。

## マルチプレイ

- Firebase Realtime Database を使用。
- 最大 6 人まで同一 ROOM ID へ参加可能。
- 同期対象は自機位置、HP、DOWN 状態、スコア、装備パーツ、直近の味方弾。
- 敵と敵弾は各クライアントで軽量に処理しつつ、味方表示、弾消し、復帰支援を成立させる。
- onDisconnect で退室処理を行う。
- 送信間隔は約 85ms に抑え、メモリと通信量を節約する。

## 軽量化方針

- 画像素材を使わず、機体、敵、弾、エフェクトは Phaser Graphics でコード描画する。
- BGM / SE は Web Audio API でプロシージャル生成する。
- 画面外の敵、弾、寿命切れ弾は即時破棄する。
- 弾数は上限を設け、古い弾を削除する。
- Firebase には必要最低限の player snapshot のみ送る。
- DOM UI はメニューと HUD に限定し、戦闘中の中央視界を塞がない。
