# 付録：Windowsデスクトップシステム実装仕様（追記）

## A. 実装済みWindowsデスクトップ機能一覧

本章は仕様書本文に記載されていないWindowsデスクトップ互換機能を補足します。
全機能はGodot 4.6 GDScriptでコードベース（.tscnなし）で実装済みです。

---

## A-1. コアシステム（scripts/core/）

| ファイル | 役割 |
|---|---|
| `WindowManager.gd` | ウィンドウ生成・登録・ZOrder・フォーカス・プロセスリスト管理（オートロード） |
| `SoundManager.gd` | BGM/SE/マスター音量管理・クロスフェード対応（オートロード） |
| `RecycleBin.gd` | ゴミ箱データ（削除・復元・完全削除・空にする）管理（オートロード） |
| `AppLauncher.gd` | アプリ起動一元管理・スクリプトパスマッピング（オートロード） |
| `BaseWindow.gd` | 全ウィンドウの基底クラス（コードでUI自動構築） |
| `SceneBuilder.gd` | StyleBox生成ユーティリティ |

## A-2. ウィンドウシステム機能詳細 (BaseWindow.gd)

- **タイトルバードラッグ移動**（画面外Clamp付き）
- **リサイズ**（右端・下端・角の6方向）
- **最小化**（コンテンツ非表示・タイトルバーのみ表示）
- **最大化（復元）**（画面全体へ拡張・元サイズへ復元）
- **閉じる（✕）**（WindowManagerへ登録解除・queue_free）
- **フォーカス制御**（クリックしたウィンドウをZオーダー最前面へ）

## A-3. デスクトップシステム機能詳細 (Desktop.gd)

- **壁紙変更**：任意画像ファイルを選択して壁紙として設定
- **アイコン管理**：デフォルト7種を起動時に自動配置
- **アイコンドラッグ移動**：グリッドスナップ（80px単位）
- **アイコンダブルクリック**：対応アプリを起動
- **アイコン右クリックメニュー**：開く / ゴミ箱へ削除 / 名前の変更 / プロパティ
- **デスクトップ右クリックメニュー**：表示切替 / アイコン整列 / 新規フォルダ / 壁紙変更 / ディスプレイ設定
- **ラバーバンド選択**：左クリックドラッグで複数アイコン選択

## A-4. タスクバー機能詳細 (Taskbar.gd)

- **スタートメニュー**：全アプリ一覧・シャットダウンボタン
- **ウィンドウボタン**：起動中ウィンドウごとのボタン（クリックでフォーカス）
- **時計表示**：時分 + 日付（1秒ごと更新）
- **音量ポップアップ**：マスター/BGM/SEのスライダーを展開

## A-5. ゴミ箱システム (RecycleBin.gd + RecycleBinApp.gd)

- アイコン右クリック→「削除」でゴミ箱シングルトンへデータ格納
- ゴミ箱アイコンのラベルに件数を反映（例：ゴミ箱 (3)）
- ゴミ箱ウィンドウ：一覧表示 / 選択復元 / 選択完全削除 / 全削除（空にする）
- 復元時はデスクトップへアイコンを再生成（元位置に戻す）

## A-6. アプリ一覧

| アプリ | ファイル | 主な機能 |
|---|---|---|
| タスクマネージャー | TaskManager.gd | プロセス一覧・CPU/メモリ表示・強制終了（確認ダイアログ付き）|
| メモ帳 | Notepad.gd | テキスト編集・開く/保存/名前を付けて保存・文字数カウント |
| ファイルエクスプローラー | FileExplorer.gd | ディレクトリ閲覧・ツリービュー・履歴ナビ・検索フィルタ |
| 時計 | ClockApp.gd | デジタル時計・タイマー（h/m/s設定）・ストップウォッチ（ラップ機能付き） |
| 音量ミキサー | VolumeMixer.gd | マスター/BGM/SE 個別スライダー・リアルタイム反映 |
| 設定 | Settings.gd | 解像度変更・フルスクリーン切替・音量・言語 |
| ゴミ箱 | RecycleBinApp.gd | 削除アイテム管理・復元・完全削除・空にする |
