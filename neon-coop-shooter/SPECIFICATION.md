# グリッドノヴァ（GRIDNOVA） — 仕様書

---

## 1. 概要・前提条件

### 1.1 ゲームタイトル
**グリッドノヴァ**（GRIDNOVA）

### 1.2 ジャンル
協力型シューティングゲーム（縦スクロール系ボスラッシュ）

### 1.3 プラットフォーム
- **対応環境**: スマートフォンブラウザ（Chrome/Safari推奨）
- **解像度**: 360×640px 固定キャンバス（9:16アスペクト比）
- **入力方式**: タッチ入力（マウス入力も対応）
- **対応OS**: iOS / Android / PC（いずれもブラウザ上で動作）

### 1.4 コンセプト・世界観
- **ネオン × メカ**: サイバーパンクな発光表現と、メカニカルなパーツの組み合わせ。
- **世界観**: AI「GRID」が暴走し世界のインフラを掌握。人類はメカフレームを駆り、最後のレジスタンスとして戦う。
- **四角形・幾何学図形**を基調としたスタイリッシュなデザイン。
- ロボットアニメやSFメカのような「換装」「変形」のロマンを取り入れた演出。
- 重い画像ファイルを使わず、**Canvas APIのプリミティブ描画**（矩形、円、線）と `shadowBlur` / `shadowColor` でネオングロー表現。

### 1.5 プレイ人数
- **ソロプレイ**: 1人
- **マルチプレイ**: 2人〜4人（リアルタイム協力）

### 1.6 技術スタック
| 要素 | 技術 |
|------|------|
| フロントエンド | HTML5 Canvas, CSS3, JavaScript (ES Modules) |
| 通信 | Firebase Realtime Database (v10.7.1 CDN) |
| ホスティング | Firebase Hosting (`neon-coop-shooter.web.app`) |
| フォント | Orbitron (見出し), Rajdhani (本文) — Google Fonts |
| データ保存 | localStorage (クライアント側、ガチャ/装備/設定) |

## 2. アウトゲーム（メニュー画面）

### 2.1 画面一覧
| 画面名 | screen ID | 概要 |
|--------|-----------|------|
| タイトル | `screen-title` | ゲーム起動時の最初の画面 |
| ステージ選択 | `screen-stage` | プレイするステージを選択 |
| ロビー | `screen-lobby` | マルチプレイのマッチング待機 |
| カスタマイズ | `screen-customize` | パーツ装備変更＋プレビュー |
| ガチャ | `screen-gacha` | コインでパーツを入手 |
| 遊び方 | `screen-howto` | 操作説明 |
| クレジット | `screen-credits` | BGM選択・音量調整・素材クレジット |
| リザルト | `screen-result` | ミッション結果表示 |

### 2.2 タイトル画面
- **背景キャンバス**: ダークグリッド背景 (`#05050d`) + シアン微細パーティクル（15個、ゆっくり浮遊）
- **機体プレビュー**: 画面中央やや下に、現在の装備構成を**3倍スケール・35%透過**で表示（レンダラーの描画メソッドを使用）
- **タイプライターアニメーション**: 「グリッド ノヴァ」が1文字ずつ表示される
  - サブタイトル: 「対 GRID 掌討作戦」
  - 2文字ごとにキー音（`titleShow` SE）を再生
  - 全文字表示完了時に衝撃音（`impact` SE）を再生
- **ボタン構成**:
  - `シングルプレイ / SINGLE PLAY` — ステージ選択へ（ソロモード）
  - `マルチプレイ / MULTI PLAY` — ステージ選択へ（マルチモード）
  - `アイコトバ — PASSWORD` 入力欄（空欄＝自動2人マッチ、入力あり＝合言葉4人マッチ）
  - `カスタマイズ / CUSTOMIZE`
  - `ガチャ / GACHA`
  - `アソビカタ / HOW TO PLAY`
  - `クレジット / CREDITS`
- **バージョン表示**: `v1.0.0`
- **ボタンデザイン**: 全ボタンが**カタカナ（メイン）＋英語（サブ）の二段構成**

### 2.3 ステージ選択画面
- **モード表示**: 現在のプレイモードをバッジで表示
  - `SINGLE PLAY` / `MULTI (自動マッチ 2人)` / `MULTI (合言葉: xxxx)`
- ステージボタンをタップで選択
  - ソロモード: 即座にゲーム開始
  - マルチモード: ロビー画面へ遷移

### 2.4 ロビー画面
- **自動マッチ（パスワード無し）**: 最大2人。Firebase上のランダムロビーに参加/作成。2人揃ったら自動開始。
- **合言葉マッチ**: 最大4人。全員が「準備完了」ボタンを押すとホストがゲーム開始。
- プレイヤー一覧がリアルタイムで更新表示される
- 切断時: `onDisconnect` でプレイヤー自動削除

### 2.5 カスタマイズ画面
- **機体プレビュー**: 200×200px の `preview-canvas` に装備機体をリアルタイムアニメーション描画
  - レンダラーの `_drawBackpack`, `_drawBody`, `_drawMainWeapon`, `_drawSubWeapon`, `_drawAccessory` メソッドを使用
  - **2倍スケール**で描画、サブ武装は「展開状態」（`isStopped = true`）で表示
  - `requestAnimationFrame` によるアニメーションループ（customize画面を離れると自動停止）
- **スロット一覧**: 5部位（ボディ/メイン/サブ/バック/アクセ）の現在装備名を表示
- **パーツ選択**: スロットをタップ → 所持パーツの一覧が表示 → **装着してもリストは閉じずそのまま**（複数パーツを試せる）
  - 装備中パーツには `equipped` クラスでハイライト表示
  - **長押し（500ms）**: パーツ詳細ダイアログを表示
    - 専用キャンバス（30×120px）にそのパーツを装備した機体を3.5倍スケールで描画
    - パーツ名・レアリティ・説明・ステータス（ダメージ、発射間隔、CD等）を表示
    - SE（`equip`）を再生

### 2.6 ガチャ画面
- 100コインで1回引ける
- ガチャプールはデフォルト装備（Standard Frame, Rapid Vulcan, Sniper Cannon, Boost Vernier）を**除外**
- 結果はパーツ名・レアリティ・説明を表示、枚の色がパーツカラーに変化
- 被りパーツは重複加算なし（既に所持していても所持扱い）

### 2.7 遊び方画面（2ページ構成）

#### ページ1: 基本操作
- **キャンバスイラスト**: 左側に現在装備の自機（Canvas描画）、右側にボス敵（SCOUT）、中央に「VS」テキスト、弾丸が飛び交う様子を描画
- 操作説明：
| 操作 | アイコン | 説明 |
|------|---------|------|
| ドラッグ | 👆 | 自機を移動。指の少し上に照準 |
| メイン武装 | 🔫 | 常時自動発射＋停止中はサブ追加 |
| ダブルタップ | 💥 | ボム（狭範囲高威力の必殺技） |
| 上スワイプ | ⬆️ | バックパックに応じた回避行動 |
| 蘇生 | 🤝 | 仲間の近くで3秒停止 |

#### ページ2: マッチング・ガチャ・カスタマイズ
- **マッチング**: シングル（ソロ）、マルチ（自動2人 / 合言葉で4人）
- **カスタマイズ**: 5つのパーツ（ボディ/メイン/サブ/バック/アクセ）を換装
- **ガチャ**: 100コインでパーツ入手、ボス撃破で50コイン＋ステージクリアで100コイン
- **移動速度**: バックパックにより決定（遅:4 / 普:6 / 速:8）

### 2.8 クレジット・設定画面
- **BGM選択**: BGMリストから選択可（ラジオボタン方式）
- **BGM素材**: nons works 様 (https://x.com/nons_works)
- **効果音素材**: 効果音ラボ 様 (https://soundeffect-lab.info/)
- **フォント素材**: 廻想体ネクストUP B (Moji-Waku Kenkyu 様)

### 2.9 リザルト画面
- **ミッションクリア**: 緑色テキスト「ミッションクリア / MISSION COMPLETE」+ クリアタイム表示 + 100コイン獲得
- **ミッション失敗**: 赤色テキスト「ミッションシッパイ / MISSION FAILED」+ 経過時間表示

### 2.10 フッター（常時表示）

## 3. インゲーム操作・仕様

### 3.1 移動
- **ドラッグ操作**: 指の位置から上方向に60pxオフセットした位置に自機が追従（`PLAYER_OFFSET_Y = 60`）
- **移動速度**: **バックパックによって決定**（後述）
  - 遅: 4px/frame、普: 6px/frame、速: 8px/frame
- **移動制限**: `x: 15〜345`, `y: 30〜580`

### 3.2 メイン射撃（常時発射）
- メイン武装は**常に自動発射**される（移動中・停止中どちらでも）
- 発射間隔は `main.fireRate` (ms) で決定
- Auto-Reloaderアクセサリ装備時: fireRate × 0.7（30%高速化）

### 3.3 サブ射撃（停止時に追加発射）
- 移動入力が止まってから **200ms経過**（`STOP_THRESHOLD`）で「停止状態」に移行
- 停止状態ではメインに加えてサブ武装が**追加で発射**される
- 視覚的にサブ武装が「展開」するアニメーション付き

### 3.4 ボム（ダブルタップ）
- ダブルタップ判定: 300ms以内にタップ2回
- ボディパーツにより発動するボムの種類が異なる（後述）
- **範囲**: 拡張速度 +4px/frame（狭め）
- **威力**: バーストウェーブ 15ダメージ/frame、オメガレーザー 10ダメージ/frame（高威力）
- **クールダウン**: ボディパーツの `bombCooldown` (ms) で決定
- Energy Condenserアクセサリ装備時: cooldown × 0.6

### 3.5 回避行動（上スワイプ）
- 上スワイプ判定: 400ms以内に60px以上上方向スワイプ（横ブレ80px以内）
- バックパックの `actionType` に応じた動作を実行
- **クールダウン**: バックパックの `cooldown` (ms) で決定

### 3.6 被弾・ゲームオーバー
- **ヒットボックス**: 1px（自機中心の極小判定）
- **被弾時**: HP-1 + 2秒間無敵（`INVINCIBLE_TIME = 2000`）+ 画面振動 + 赤パーティクル
- **HP 0以下**: 死亡
  - ソロプレイ: 1秒後にゲームオーバー
  - マルチプレイ: 味方が全員死亡していなければ蘇生可能

### 3.7 蘇生（マルチプレイ）
- `REVIVE_RANGE = 40px` 以内で `REVIVE_TIME = 3000ms` 停止で蘇生
- Revive Kitアクセサリ装備時: 蘇生時間 × 0.5 = 1.5秒

### 3.8 ジャンプ（回避行動の一種）
- Boost Vernier装備時の回避行動
- 無敵時間: 1500ms
- 視覚的に自機が上昇・縮小する `jumpProgress` アニメーション

## 4. ステージ・ボス構成

### 4.1 ステージ1: NEON FORTRESS（3ウェーブ制ボスラッシュ）

| Wave | ボス名 | タイプ | 色 | サイズ | HP | 移動速度 | 難易度 |
|------|--------|--------|-----|--------|------|----------|--------|
| 1 | SCOUT | geometric | `#ff4466` | 30 | 500 | 0.8 | ★☆☆ |
| 2 | SENTINEL | fortress | `#aa44ff` | 40 | 800 | 0.6 | ★★☆ |
| 3 | OVERLORD | mech | `#ffee00` | 50 | 1500 | 1.0 | ★★★ |

### 4.2 攻撃パターン詳細

| パターン | 説明 | パラメータ | 出現Wave |
|----------|------|-----------|---------|
| `radial` | 全方位均等に弾を発射 | bullets(数), speed, interval(ms) | 1,2,3 |
| `aimed` | プレイヤーを狙って発射（拡散spread=0.15×index） | bullets, speed, interval | 1,2,3 |
| `spiral` | 回転しながら連続弾発射（角度 +0.15/frame） | bullets, speed, interval, duration(ms) | 2,3 |
| `ring` | 大量弾をリング状に同時発射（角度offset=now×0.001） | bullets, speed, interval | 2 |
| `homing` | **誘導弾**: プレイヤーを追尾（旋回速度制限あり、5秒で消滅） | bullets, speed, interval, turnRate | 3 |
| `charge_rush` | **突進攻撃**: 警告表示後にボスが画面下方向へ突進 | speed, interval, warning(ms) | 3 |
| `laser_warning` | 警告線表示→横方向レーザー照射 | duration, laserWidth, interval | — |

### 4.3 Wave 1: SCOUT の攻撃パターン
```
radial: 8弾, speed:2, 2500ms間隔
aimed:  2弾, speed:3, 2000ms間隔
```
→ 基本的な弾幕。放射弾は隙間が大きく避けやすい。

### 4.4 Wave 2: SENTINEL の攻撃パターン
```
radial: 16弾, speed:2.5, 2000ms間隔
aimed:  4弾,  speed:3.5, 1500ms間隔
spiral: 1弾,  speed:2,   80ms間隔, 2000ms持続
ring:   24弾, speed:1.5, 3500ms間隔
```
→ 弾幕が激しい。渦巻きとリングが重なると密度が高くなる。

### 4.5 Wave 3: OVERLORD の攻撃パターン
```
radial:      20弾, speed:3,   1800ms間隔
aimed:       5弾,  speed:4,   1200ms間隔
spiral:      2弾,  speed:2.5, 60ms間隔, 3000ms持続
homing:      3弾,  speed:2.5, 4000ms間隔, turnRate:0.03
charge_rush: speed:8, 10000ms間隔, warning:1500ms
```
→ 弾が多く、誘導弾が追いかけてくるため回避行動が必須。突進もあり最も危険。

### 4.6 ウェーブ遷移
1. ボスのHPが0以下になると `_bossDefeated()` が呼ばれる
2. ボスオブジェクトを即座に `null` にし、敵弾を全消去
3. 撃破パーティクル + 画面振動 + 撃破SE
4. **50コイン**獲得（ウェーブごと）
5. **2秒後**に次のウェーブを開始
6. 最終ウェーブ撃破後: ステージクリア → リザルト画面（+100コイン）

### 4.7 マルチプレイ時のHP調整
- `getScaledHP(baseHP, playerCount)`
- 2人以上: `HP × (1 + (playerCount - 1) × 0.75)`
- 例: 2人でSCOUT → 500 × 1.75 = 875

## 5. パーツシステム（カスタマイズ）

### 5.1 パーツスロット構成（全5部位）
自機は以下の5つのパーツで構成され、ガチャで入手して組み替える。

| # | スロット | 役割 | 影響する要素 |
|---|---------|------|-------------|
| 1 | Body (ボディ) | 機体のコア | HP基礎値、ボムの種類・クールダウン |
| 2 | Main Weapon (メイン武装) | 常時射撃 | 発射パターン、ダメージ、発射間隔 |
| 3 | Sub Weapon (サブ武装) | 停止時追加射撃 | 発射パターン、ダメージ、発射間隔 |
| 4 | Backpack (バックパック) | 回避行動＋移動速度 | 上スワイプの動作種類、クールダウン、移動速度 |
| 5 | Accessory (アクセサリ) | パッシブ効果 | 各種ステータス補正 |

### 5.2 デフォルト装備
```javascript
{
    body: 'standard_frame',       // HP:3, バーストウェーブ
    mainWeapon: 'rapid_vulcan',   // 連射機関銃
    subWeapon: 'sniper_cannon',   // 狙撃砲
    backpack: 'boost_vernier',    // ジャンプ回避, 移動速度:遅(4)
    accessory: 'none'             // なし
}
```

### 5.3 ボディ (Body) 一覧

| ID | 名前 | HP | ボムタイプ | ボムCD | レア | 色 | 説明 |
|----|------|-----|-----------|--------|------|-----|------|
| `standard_frame` | Standard Frame | 3 | `burst_wave` | 15秒 | C | `#00f0ff` | バーストウェーブ: 衝撃波で周囲の弾を消しつつダメージ |
| `assault_frame` | Assault Frame | 2 | `omega_laser` | 18秒 | B | `#ff2244` | オメガレーザー: 前方に極太ビーム照射 |
| `fortress_frame` | Fortress Frame | 5 | `absolute_barrier` | 25秒 | A | `#aa44ff` | アブソリュートバリア: 自分と周囲の味方を無敵化 |
| `speedster_frame` | Speedster Frame | 2 | `clock_up` | 20秒 | S | `#ffee00` | クロックアップ: 自分以外の時間を5秒間0.3倍速に |

#### ボム効果の詳細
- **バーストウェーブ (`burst_wave`)**: 自機中心に膨張する衝撃波。範囲内の敵弾を消去 + ボスにダメージ(15/frame)。持続500ms。
- **オメガレーザー (`omega_laser`)**: 自機位置から上方に幅40pxのレーザー照射。ボスに10ダメージ/frame。持続500ms。
- **アブソリュートバリア (`absolute_barrier`)**: バーストウェーブと同じ敵弾消去 + プレイヤーを600ms無敵化。
- **クロックアップ (`clock_up`)**: ボスの攻撃タイマーと弾速を0.3倍に。5秒間持続。

### 5.4 メイン武装 (Main Weapon) 一覧

| ID | 名前 | 発射間隔 | ダメージ | パターン | レア | 色 | 説明 |
|----|------|----------|---------|---------|------|-----|------|
| `rapid_vulcan` | Rapid Vulcan | 100ms | 5 | `vulcan` | C | `#00f0ff` | 素直な直進弾。安定した連射力 |
| `wide_spread` | Wide Spread | 200ms | 4 | `spread` | B | `#00ff88` | 3way拡散弾（角度±0.3rad） |
| `homing_missiles` | Homing Missiles | 350ms | 6 | `homing` | A | `#ff8800` | ボスを自動追尾するミサイル |
| `plasma_cutter` | Plasma Cutter | 150ms | 12 | `cutter` | S | `#ff00aa` | 大型の貫通弾（pierceフラグ） |

#### メイン武装の発射ロジック
- **vulcan**: 自機真上から直進弾(vy=-10)を1発
- **spread**: 自機から3方向に発射（-0.3, 0, +0.3 rad偏差、vy=-8基準）
- **homing**: ボスへの角度を計算し追尾弾を発射（追尾加速0.3/frame、最大速度8）
- **cutter**: 幅広の貫通弾(radius:8, vy=-6, pierce:true)。敵を貫通しても消えない

### 5.5 サブ武装 (Sub Weapon) 一覧

| ID | 名前 | 発射間隔 | ダメージ | パターン | レア | 色 | 説明 |
|----|------|----------|---------|---------|------|-----|------|
| `sniper_cannon` | Sniper Cannon | 800ms | 40 | `sniper` | C | `#00f0ff` | 左右の砲身から高速弾(vy=-18)を2発 |

## 6. パーツ別ビジュアル仕様（自機見た目変化）

### 6.1 描画原則
- すべて **Canvas APIのプリミティブ描画**（`fillRect`, `arc`, `lineTo` 等）
- **ネオングロー**: `ctx.shadowColor` + `ctx.shadowBlur` で表現
- 重い画像アセットは一切使用しない

### 6.2 自機レイヤー構成（描画順）
1. **バックパック** — ボディの奥側（下側）に `globalAlpha = 0.45` で描画
2. **ボディ** — 機体コア。中心14×14pxの四角形 + 内部パターン + 白い中心点(4×4)
3. **メイン武装** — ボディ前方（上側）に砲身として描画
4. **サブ武装** — ボディ両脇に固定配置（左右対称または片側）
5. **アクセサリ** — 自機周囲に展開・回転・浮遊

## 10. 描画・レンダリング仕様

### 10.1 背景
- 背景色: `#05050d`（ほぼ黒のダークブルー）
- グリッド: シアン(`rgba(0,240,255,0.03)`)、40px間隔

### 10.2 ボス描画
- `drawBoss(boss, time)`: ボスの基本形を描画
- 入場アニメ: y=-60 から targetY まで 2px/frame で下降
- 被弾フラッシュ: `damageFlash > 0` 時にコアを白くフラッシュ
- 移動: 2秒ごとにランダムなX座標目標を設定し、`speed` で水平移動

### 10.3 弾丸描画
- **自機弾**: ネオングローつきの小さな矩形（`shadowBlur = 6`）
- **敵弾**: 赤系グローの矩形（通常 radius:4〜5）
- **ホーミング弾**: radius:6 のやや大きめの弾。ゆっくり旋回しながらプレイヤーを追尾

### 10.4 エフェクト・パーティクル
- `addParticles(x, y, color, count, speed)`: パーティクルの追加
- ボス撃破: 30粒, speed:6
- 被弾: 10粒, speed:4, 赤色
- テレポート残像: 12粒, speed:5
- 各パーティクルは毎フレーム `life -= 0.02` で減衰し、0以下で消滅

### 10.5 画面振動
- `screenShake`: 初期値を設定すると毎フレーム ×0.9 で減衰
- ボス撃破: 15
- 被弾: 8
- ボム: 10

## 12. 入力ハンドラ仕様

### 12.1 タッチ/マウスイベント
- `touchstart` / `mousedown` → `_onStart`: タッチ開始、ダブルタップ判定開始
- `touchmove` / `mousemove` → `_onMove`: ドラッグ追従
- `touchend` / `mouseup` → `_onEnd`: タッチ終了、スワイプ判定

### 12.2 座標変換
- `_getPos(e)`: DOMの矩形とキャンバスのサイズ比からゲーム内座標を算出
- `scaleX = canvas.width / rect.width`, `scaleY = canvas.height / rect.height`

### 12.3 ジェスチャー判定
- **ダブルタップ**: 前回タップから300ms以内に再度タップ
- **上スワイプ**: タッチ開始から400ms以内、Yが-60px以上移動（上方向）、Xが±80px以内
- **移動判定**: 開始位置から5px以上動いた場合 `moving = true`
