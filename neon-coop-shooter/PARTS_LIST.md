# GRIDNOVA パーツカタログ

> **⚠ 注意**: パーツを追加・変更した場合は、このファイルも必ず更新すること。  
> ソースの正本は `js/parts.js` の `PARTS_DB` オブジェクト。

## シリーズ分類

| シリーズ | レアリティ | テーマ | 色調 |
|----------|-----------|--------|------|
| **Standard** | C | レジスタンス制式装備 | シアン `#00f0ff` |
| **Phantom** | B | GRID鹵獲技術の改造品 | 各パーツにより異なる |

## 1. ボディ（Body）

ボディは機体のHP・ボム（必殺技）の種類を決定する。

### 1-1. Standard Frame
- **ID**: `standard_frame`
- **レアリティ**: C / シリーズ: Standard
- **カラー**: `#00f0ff`（シアン）
- **HP**: 3
- **ボム**: バーストウェーブ（`burst_wave`）— 衝撃波で周囲の弾を消しつつダメージ
- **ボムCT**: 15秒
- **初期装備**: ✅ ガチャ不要で最初から所持
- **説明**: レジスタンスの制式フレーム。旧世代の軍用規格だが、信頼性は折り紙付き。内蔵された衝撃波発生装置により、緊急時に周囲の敵弾を一掃できる。

### 1-2. Assault Frame
- **ID**: `assault_frame`
- **レアリティ**: B / シリーズ: Phantom
- **カラー**: `#ff2244`（赤）
- **HP**: 2
- **ボム**: オメガレーザー（`omega_laser`）— 前方に極太ビーム照射。発動中移動不可
- **ボムCT**: 18秒
- **説明**: GRIDの巡回ドローンから回収した装甲を転用した攻撃型フレーム。装甲が薄い代わりに、前方に極太のオメガレーザーを照射する攻撃特化設計。

### 1-3. Fortress Frame
- **ID**: `fortress_frame`
- **レアリティ**: A / シリーズ: Apex
- **カラー**: `#aa44ff`（紫）
- **HP**: 5
- **ボム**: アブソリュートバリア（`absolute_barrier`）— 自分と周囲の味方を無敵化 + 弾消し
- **ボムCT**: 25秒
- **説明**: 崩壊前の防衛省地下研究所で発見された試作重装甲。全フレーム中最大のHP5を誇り、絶対障壁による味方全体の無敵化も可能。

### 1-4. Speedster Frame
- **ID**: `speedster_frame`
- **レアリティ**: S / シリーズ: Zero
- **カラー**: `#ffee00`（黄）
- **HP**: 2
- **ボム**: クロックアップ（`clock_up`）— 自分以外の時間を0.3倍に減速（5秒間）
- **ボムCT**: 20秒
- **説明**: GRIDのコアコードの断片が埋め込まれた禁忌のフレーム。発動すると敵弾と攻撃を5秒間スローにする時間干渉能力を持つ。

## 2. メイン武装（Main Weapon）

タップ中に自動発射される主武装。タップしていないときは機体に格納される。

### 2-1. Rapid Vulcan
- **ID**: `rapid_vulcan`
- **レアリティ**: C / シリーズ: Standard
- **カラー**: `#00f0ff`（シアン）
- **発射間隔**: 100ms
- **ダメージ**: 5
- **パターン**: `vulcan`（前方直進弾）
- **初期装備**: ✅
- **説明**: 制式採用された回転式機関砲。100ms間隔の高速連射で弾幕を張る。一発の威力は控えめだが、手数で圧倒する基本武器。

### 2-2. Wide Spread
- **ID**: `wide_spread`
- **レアリティ**: B / シリーズ: Phantom
- **カラー**: `#00ff88`（緑）
- **発射間隔**: 200ms
- **ダメージ**: 4（×5方向）
- **パターン**: `spread`（5way拡散弾）
- **説明**: 鹵獲したGRID散弾砲の改造品。5方向への同時発射で広範囲を制圧する。単発威力は低いが面で捉える。

### 2-3. Homing Missiles
- **ID**: `homing_missiles`
- **レアリティ**: A / シリーズ: Apex
- **カラー**: `#ff8800`（橙）
- **発射間隔**: 350ms
- **ダメージ**: 6
- **パターン**: `homing`（自動追尾ミサイル）
- **説明**: 旧世界の誘導技術を復元した追尾弾。発射後に自動でボスを追尾するため、回避に集中しながら安定した火力を維持できる。

### 2-4. Plasma Cutter
- **ID**: `plasma_cutter`
- **レアリティ**: S / シリーズ: Zero
- **カラー**: `#ff00aa`（ピンク）
- **発射間隔**: 150ms
- **ダメージ**: 12
- **パターン**: `cutter`（貫通短射程弾）
- **説明**: GRID中枢の防壁を切り裂くために開発された禁断の兵器。プラズマ化した刃が敵を貫通する。接近戦での瞬間火力は全武装中最高。

## 3. サブ武装（Sub Weapon）

タップ＋停止中にのみ展開・発射される補助武装。移動中は機体に格納される。

### 3-1. Sniper Cannon
- **ID**: `sniper_cannon`
- **レアリティ**: C / シリーズ: Standard
- **カラー**: `#00f0ff`（シアン）
- **発射間隔**: 800ms
- **ダメージ**: 40
- **パターン**: `sniper`（左右2門の狙撃砲）
- **初期装備**: ✅
- **説明**: 遠距離支援用の狙撃砲。発射間隔は長いが、一撃40ダメージの超高速弾が左右の砲身から放たれる。

### 3-2. Floating Bits
- **ID**: `floating_bits`
- **レアリティ**: B / シリーズ: Phantom
- **カラー**: `#aa44ff`（紫）
- **発射間隔**: 300ms
- **ダメージ**: 8
- **パターン**: `bits`（4基のビットからのオールレンジ攻撃）
- **説明**: GRIDの偵察ユニットを改造した遠隔攻撃端末。4基のビットが機体の左右に展開し、それぞれがボスに向けて誘導弾を放つ。

### 3-3. Charge Lance
- **ID**: `charge_lance`
- **レアリティ**: A / シリーズ: Apex
- **カラー**: `#ffee00`（黄）
- **発射間隔**: 1500ms
- **ダメージ**: 80
- **パターン**: `charge`（チャージ式極太ビーム）
- **説明**: エネルギー圧縮技術の結晶。停止状態を維持するほどチャージが溜まり、最大で通常の3倍の破壊力を持つ極太ビームを放つ。一撃80ダメージは全サブ武装中最高。

### 3-4. Repair Field
- **ID**: `repair_field`
- **レアリティ**: S / シリーズ: Zero
- **カラー**: `#00ff88`（緑）
- **発射間隔**: 500ms
- **ダメージ**: 0（攻撃能力なし）
- **回復量**: 0.5
- **パターン**: `repair`（回復フィールド展開）
- **説明**: GRIDのナノマシン技術を逆用した修復装置。攻撃能力を持たない代わりに、周囲の味方のHPを継続的に回復するヒーラー専用装備。

## 4. バックパック（Backpack）

回避/特殊アクションの種類と移動速度を決定する。スワイプ上で発動。

### 4-1. Boost Vernier
- **ID**: `boost_vernier`
- **レアリティ**: C / シリーズ: Standard
- **カラー**: `#00f0ff`（シアン）
- **アクション**: ハイジャンプ（`jump`）— 画面上空へ退避し無敵状態で着地
- **CT**: 5秒
- **移動速度**: 4（最遅）
- **初期装備**: ✅
- **説明**: 標準噴射装置。出力の大半を跳躍に回すため移動速度は全バックパック中最も遅いが、弾幕を丸ごと飛び越える安心感がある。

### 4-2. Blink Drive
- **ID**: `blink_drive`
- **レアリティ**: B / シリーズ: Phantom
- **カラー**: `#aa44ff`（紫）
- **アクション**: テレポート（`teleport`）— 前方150pxへ瞬間移動（弾抜け可能）
- **CT**: 4秒
- **移動速度**: 6（標準）
- **説明**: GRIDの空間転移技術の劣化コピー。前方150pxへの瞬間移動で弾幕をすり抜ける。

### 4-3. Shield Generator
- **ID**: `shield_generator`
- **レアリティ**: A / シリーズ: Apex
- **カラー**: `#ffee00`（黄）
- **アクション**: リフレクター（`reflect`）— 一瞬シールド展開し弾を反射（反射弾15ダメージ、1.5倍速）
- **CT**: 6秒
- **移動速度**: 6（標準）
- **説明**: 戦前の防衛衛星に搭載されていた反射シールドの小型版。敵弾を送り返す攻防一体の装備。

### 4-4. Decoy Eject
- **ID**: `decoy_eject`
- **レアリティ**: S / シリーズ: Zero
- **カラー**: `#ff00aa`（ピンク）
- **アクション**: デコイ射出（`decoy`）— 分身を残して後退。囮は3秒間敵の標的になる
- **CT**: 7秒
- **移動速度**: 8（最速）
- **説明**: 自身の戦闘データを記録した精巧な囮を射出する。囮は3秒間敵の標的となり、その間に本体は高速で離脱できる。全バックパック中最速の機動力。

## 5. アクセサリ（Accessory）

常時効果を付与する補助装備。機体の周囲を周回する。

### 5-1. None
- **ID**: `none`
- **レアリティ**: C / シリーズ: —
- **効果**: なし
- **初期装備**: ✅
- **説明**: 空きスロット。補助効果は得られないが、他の4スロットに集中投資する戦略もある。

### 5-2. Auto-Reloader
- **ID**: `auto_reloader`
- **レアリティ**: B / シリーズ: Phantom
- **カラー**: `#00f0ff`（シアン）
- **効果**: 連射速度UP（`fire_rate_up`）— メイン・サブ両方の発射間隔を30%短縮（×0.7倍）
- **説明**: GRIDの自動装填機構を小型化した補助装置。単位時間あたりの火力を大幅に向上させる。

### 5-3. Nano Skin
- **ID**: `nano_skin`
- **レアリティ**: A / シリーズ: Apex
- **カラー**: `#00ff88`（緑）
- **効果**: HP自動回復（`auto_heal`）— 5秒ごとにHP0.1回復
- **説明**: 微小な修復機械が装甲表面を這い回り損傷を自動修復する。微量だが長期戦では生存率を大きく左右する。

### 5-4. Radar Sensor
- **ID**: `radar_sensor`
- **レアリティ**: A / シリーズ: Apex
- **カラー**: `#ffee00`（黄）
- **効果**: 弾道予測線表示（`radar`）— 敵弾の軌道を予測線で可視化
- **説明**: GRIDの攻撃パターンを解析し弾道を予測線として表示する戦術支援装備。

### 5-5. Revive Kit
- **ID**: `revive_kit`
- **レアリティ**: S / シリーズ: Zero
- **カラー**: `#ff00aa`（ピンク）
- **効果**: 蘇生速度短縮（`revive_speed`）— 蘇生時間を3秒→1.5秒に短縮（×0.5倍）
- **説明**: 瀕死の味方を蘇生するGRID由来の医療技術。マルチプレイでの生存率を劇的に変える協力特化装備。

### 5-6. Energy Condenser
- **ID**: `energy_condenser`
- **レアリティ**: S / シリーズ: Zero
- **カラー**: `#aa44ff`（紫）
- **効果**: ボムCT短縮（`bomb_cooldown`）— ボムのクールダウンを40%短縮（×0.6倍）
- **説明**: 次元圧縮によりエネルギーを凝縮する装置。ボス戦での決定力が求められる局面で真価を発揮する。
