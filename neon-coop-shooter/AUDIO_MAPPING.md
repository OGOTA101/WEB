## タイトル演出

- タイトル文字「NEON FRAME」はタイプライター風に1文字ずつ表示
- 入力中は2文字ごとに `select` (決定ボタンを押す18) を再生
- 入力完了後に `impact` (文字表示の衝撃音1) を再生
- サブタイトル「CO-OP BOSS RUSH SHOOTER」がフェードイン

---

## SE差し替え方法

`js/sound.js` の `SE_FILES` オブジェクト内のファイルパスを変更するだけで反映されます:

```
SE_FILES = {
    shoot:       'assets/audio/新しいファイル.mp3',
    shootSub:    'assets/audio/新しいファイル.mp3',
    ...
};
```
