# master_scenario.csv カラム解説ガイド

> **対象者**: プランナーおよびシナリオライターの皆様へ
> **最終更新**: 2026-03-22

お疲れ様です。本ドキュメントは、ゲーム全体の進行を管理する統合マスターデータ『`master_scenario.csv`』の記述ルールや各カラムの役割についてまとめたものです。
データの入力やシナリオ作成の際に、ぜひご活用くださいませ。

---

## 📋 概要

`master_scenario.csv` は、ゲームの進行を **1つのファイルで一元管理するためのマスターデータ** です。
現実世界（デスクトップ画面）でのADVパート、LIMEの会話、システムイベント、スキンシップパート、そしてホラー演出など、すべてのイベント進行をこちらのファイルで定義していただきます。

## 📊 カラム一覧（全12列）

データの入力順にご説明いたします。空欄で問題ない項目（必須でないもの）は、カンマのみを入力して飛ばしていただいて構いません。

| # | カラム名 | 必須 | 型 | 説明 |
|---|---|---|---|---|
| 1 | **番号** | ✅ | 数値 | イベントの一意となるIDです。**千の位がDAY番号**に対応するよう設定をお願いいたします（例: 1000〜1999=DAY1）。番号の小さい順から実行されますので、後からの追加や分岐に備えて、1000, 1010, 1020...のように間隔を空けて採番してください。 |
| 2 | **機能** | ✅ | 文字列 | 実行するイベントの種類を指定します。（詳しくは後述の「機能名一覧」をご覧ください） |
| 3 | **トリガー** | ✅ | 文字列 | この行のイベントが開始される条件を指定します。（詳しくは後述の「トリガー一覧」をご覧ください） |
| 4 | **話者** | △ | 文字列 | セリフを発言するキャラクターのIDを入力します。ナレーションの場合は空欄で問題ございません。（例: `miyu`, `mio`, `ohtomo`, `koishi`, `imouto`, `自分` など） |
| 5 | **テキスト** | ✅ | 文字列 | 表示させたいセリフ、ナレーション、あるいはシステムの説明を入力します。文中に `<NAME>` と記述していただくと、ゲーム内でプレイヤーが入力した名前に自動置換されます。 |
| 6 | **キャラ表示** | △ | 文字列 | キャラクターの立ち絵を表示する場合に指定します。`キャラ名:感情` の形式でご入力ください（例: `MIYU:happy`）。立ち絵を出さない場合は空欄にしてください。 |
| 7 | **背景** | △ | 文字列 | 表示する背景画像のIDを指定します。シーン継続などで変更しない場合は空欄にしていただくことで、直前の背景がそのまま維持されます。 |
| 8 | **BGM** | △ | 文字列 | 再生するBGMのIDを指定します。変更しない場合は空欄で維持されます。BGMを止めたい場合は `BGM_STOP` とご入力ください。 |
| 9 | **SE** | △ | 文字列 | 再生する効果音のIDを指定します。指定した行が実行された瞬間に1度だけ再生されます。 |
| 10 | **選択肢** | △ | 文字列 | プレイヤーに提示する選択肢を入力します。機能が `SELECT` の場合のみ有効です。`A:選択肢1の文章/B:選択肢2の文章` のように、スラッシュ `/` で区切ってご入力ください。 |
| 11 | **演出** | △ | 文字列 | フェードインやフラッシュなどの特殊演出IDを指定します。（詳しくは後述の「演出一覧」をご覧ください） 複数の演出を同時に発動させたい場合は、`+` でお繋ぎください（例: `GLITCH+NOISE`）。 |
| 12 | **備考** | - | 文字列 | プランナー様向けのメモ書き用カラムです。ゲームの進行には一切影響いたしませんので、説明や注釈などご自由にお使いください。 |

## 🏷️ 機能名一覧

第2カラムの「機能」にご入力いただく文字列の一覧です。

| 機能名 | 説明 | 特に必要なカラム |
|---|---|---|
| **ADV** | 通常のノベルパート（会話やナレーション）を進行させます。 | 話者、テキスト、（必要に応じてキャラ表示、背景） |
| **SELECT** | プレイヤーに分岐選択肢を提示します。 | 選択肢（必須） |
| **LIME** | LIMEアプリでのメッセージ送受信を表現します。 | 話者、テキスト |
| **OS** | デスクトップ画面上でのアクション（アプリの強制起動など）を行います。 | テキスト、演出 |
| **SYSTEM** | 日付の変更、フラグ管理、ゲーム開始などのシステム処理を行います。 | テキスト |
| **SKINSHIP** | 君恋ゲーム内でのスキンシップパートを開始させます。 | 演出に `OPEN_SKINSHIP` を指定 |
| **SPECIAL** | 特殊なホラー演出や強制イベントを発生させます。 | キャラ表示、背景、演出などお好みで |

## 🔀 トリガー一覧

第3カラムの「トリガー」にご入力いただき、その行がいつ実行されるかを決定します。

| トリガー値 | 説明 |
|---|---|
| **START** | ゲーム全体の起動時に、最初に1回だけ実行されます。 |
| **AUTO** | 直前のイベント行の処理が完了し次第、待ち時間なしで自動的に実行されます。 |
| **START_GAME** | タイトル画面で「START」ボタンが押された際に実行されます。 |
| **DAY_START** | 新しい日が始まって現実世界のADVに移る前に、プレイヤーが手動でキミコイを起動するのを待つトリガーです。 |
| **DAY1〜DAY15** | 対応する日付のノベル（キミコイ）パート冒頭で実行されます。 |
| **DAYn_EVE** | 各日付の夕方（スキンシップ開始前）に実行されます。 |
| **NOVEL_START** | デスクトップ上のアプリアイコンから、ゲーム内ゲーム「キミコイ」を起動した際に実行されます。 |
| **CHOICE_A** | 直前にあったSELECT機能で、プレイヤーが「A」の選択肢を選んだ場合に実行されます。 |
| **CHOICE_B** | 直前にあったSELECT機能で、プレイヤーが「B」の選択肢を選んだ場合に実行されます。 |
| **MERGE** | 分岐していたAルート・Bルートが合流するポイントに指定します。 |
| **SKINSHIP_DONE** | スキンシップパートが終了した直後に実行されます。 |
| **DAYn_GLITCH** | ホラー演出を開始させるためのトリガーです。 |
| **{番号}_NEXT** | 特定の番号のイベントが完了した後に続くルートとして指定します。（例: `1020_NEXT`） |

## 🎵 BGMならびに🔊 SEのID一覧

第8カラム（BGM）、第9カラム（SE）で指定できるサウンドIDです。

**BGM**
* `BGM_TITLE` : タイトル画面用の楽曲
* `BGM_DAILY` : 現実世界・日常パート用の楽曲
* `BGM_KIMIKOI` : ゲーム内ゲーム『キミコイ』用のメイン楽曲
* `BGM_FINAL` : 最終日・クライマックス用の楽曲
* **(`BGM_STOP` と入力すると再生中のBGMが停止します)**

**SE（効果音）**
* `SE_NOISE` : 砂嵐のようなノイズ音
* `SE_NOTIF` : PCの一般的な通知音
* `SE_LIME_IN` : LIMEのメッセージ受信音
* `SE_LIME_OUT` : LIMEのメッセージ送信音
* `SE_GLITCH` : ホラー用の不具合音（グリッチ）
* `SE_LONG_BEEP` : 無機質な警告音（ピーーー）

## ✨ 演出ID一覧

第11カラム「演出」で指定することで、シーンに動きを持たせることができます。
組み合わせる際は `+` 記号をお使いくださいませ。（例: `GLITCH+NOISE`）

| ID | 説明 |
|---|---|
| FADE_IN | 画面を黒からゆっくりとフェードインさせます |
| FLASH | 画面を一瞬だけ真っ白に光らせます |
| DAY_SCREEN | 画面の中央に「DAY 〇」と日付を表示する演出を挟みます |
| DAY_END | その日を終了し、次の日へ進める処理を行います |
| OPEN_LIME | LIMEアプリをデスクトップ上に強制的に開かせます |
| OPEN_NOVEL | ノベルウィンドウを強制的に開かせます |
| OPEN_SKINSHIP | スキンシップパート（好感度ゲーム）への移行を行います |
| GLITCH | 画面全体を崩すグリッチエフェクトを発生させます |
| NOISE | 視覚的なブロックノイズエフェクトを発生させます |
| SCREEN_SHAKE | 画面を激しく揺らします |
| ENDING_CHECK | エンディング条件を満たしているかの判定をシステムに行わせます |

## 📝 データ入力時のご注意点とTips

### ✅ 基本的なお約束
1. **番号（第1カラム）は必ず被らない「一意の数字」** にしてください。
2. **番号の千の位はDAY番号と同調** するように設計をお願いいたします（1日目なら1000番台、2日目なら2000番台）。
3. 後から行を追加しやすいように、**10ごとの連番（1010, 1020, 1030...）**で採番しておくことをお勧めいたします。
4. キャラクターのセリフを入力する際は、必ず **「」** で囲んでください。状況説明などのナレーションは「」なしでそのままご入力ください。
5. セリフ内にカンマ（`,`）を含めたい場合は、CSVがずれないよう、テキスト全体をダブルクォーテーション（`"`）で囲んでください（例: `"「ああ、わかった。」"`）。

### ✅ 分岐（SELECT）の書き方イメージ
```csv
1180,SELECT,AUTO,,,,,,A:実は……/B:うーん……,, // ここで分岐を提示
1181,ADV,CHOICE_A,自分,「実は……」,,,,,,       // Aを選んだ時の反応
1182,ADV,CHOICE_B,自分,「うーん……」,,,,,,     // Bを選んだ時の反応
1190,ADV,1181_NEXT,...                         // Aルートの続き
1210,ADV,1182_NEXT,...                         // Bルートの続き
1230,ADV,MERGE,...                             // 最後にここでルートが合流
```

### ✅ 新しいDAY（日）を追加する時の基本テンプレート
新しく日を追加する際は、以下のような流れでご構築くださいませ。
```csv
(例: DAY2の場合、2000番台を使用)
2000,SYSTEM,DAY_START,,DAY2開始の待機,,,,,,,手動起動待ち
2010,SYSTEM,DAY2,,DAY2イベント開始,,,,,,,キミコイ内イベント開始
... （この間に各日のセリフやイベントをご記述ください） ...
2900,SYSTEM,AUTO,,DAY2_END,,,,,,DAY_END,DAY2終了・セーブ処理へ
```
