# Calorie Inc. - 魔王令嬢の甘き再侵攻 - ゲーム仕様書 v0.2

## 0. この文書の目的

本書は、Plague Inc. 型の世界拡大型シミュレーションを、ファンタジー世界の「肥満魔瘴」に翻訳したゲーム企画の統合仕様書である。  
今回の方針では、規模を無理に広げず、**4種族 / 7か国 / 1枚の世界地図**に絞って、国ごとの差・種族ごとの差・偽装と発覚の読み合いを濃くする。

### 設計の根本方針

- 元ゲームの核は、
  1. 見つかる前に広げる
  2. 見つかった後は研究を遅らせる
  3. 最後に残る地域を潰す
  という三幕構成にある。
- 本作ではそれを、
  1. 肥満魔瘴を気づかれず広げる
  2. 隠れ肥満・文化侵食・幻術で発覚を遅らせる
  3. 瘦身魔法が完成する前に、最後の抵抗国まで堕とす
  という構造へ置き換える。
- 原作の「気候耐性」「薬剤耐性」のような病原体的表現は使わず、**価値観・生活習慣・服飾・幻術・社会制度への浸透**として再設計する。

## 2. 世界観

### 2-1. 大前提

- 魔王は勇者たちに倒された。
- 魔王軍の残党は弱体化し、正面戦争ではもう勝てない。
- そこで魔王の娘は発想を変える。

> **戦って勝てないなら、戦えない世界に変えてしまえばいい。**

彼女は人々の食欲、満腹感、生活習慣、価値観へ干渉する「肥満魔瘴」を世界へ流し、  
人々を満たし、鈍らせ、抵抗しにくい社会へ変えていく。

### 2-2. 女性の扱い

- この世界では、**女性の方が平均的に魔力が強い**。
- そのため、かつて魔王を倒した勇者パーティも女性中心だった。
- ゲーム内で主に取り上げる代表キャラクターも成人女性にする。
- ただし、肥満魔瘴の影響は男女問わず世界全体に及ぶ。  
  プレイヤーが観察する“顔”が女性中心なだけで、男性も当然肥満化していく。

### 2-3. 結末

- 勝利時の結末は固定で、**最終的に全員が肥満化する**。
- ゲーム上の興味は「太るかどうか」ではなく、
  - いつ
  - どの国から
  - どれだけ気づかれずに
  - どの順番で
  世界を堕としていくかに置く。

### 5-1. 勝利条件

1. 7か国すべてに肥満魔瘴が定着している

3. 主要国が瘦身魔法の完成前に陥落している
4. すべての国で最終的に肥満化が不可逆段階へ到達する

以下のいずれかで敗北。

1. **瘦身魔法《リデュース》** が完成し、世界規模の浄化が始まる
2. 露見が早すぎて、主要交易路・祭礼・流通が封鎖され、全土展開が不可能になる
3. 研究中枢国が健在なまま、プレイヤー側の進行速度を完全に上回る

## 8. 隠れ肥満システム

### 8-1. 基本思想

本作では、肥満を単一数値にしない。  
**“実際には進んでいる肥満” と “外から見えている肥満” を分ける。**

```text
実肥満度 = 体脂肪率 / 内臓脂肪 / 筋力低下 / 代謝低下 / 生活堕落
表面肥満度 = 見た目の丸み / 服の張り / 動作の重さ / 周囲の認識
```

### 8-2. 隠れ肥満の意味

- 高い体脂肪率だが外見はまだ細く見える
- 幻影魔法で輪郭やサイズ感を誤魔化す
- コルセットや補正下着で衣服の上からは気づかれにくい
- ゆったり衣装や文化的受容によって「問題」と見なされない

### 8-3. 発覚度の概念式

```text
発覚度 =
  表面肥満度
  + 社会的不調
  + 研究者の警戒
  - 偽装値
  - 文化的受容
```

### 8-4. 段階分け

#### 実肥満度の段階
1. 食欲変化
2. 体脂肪率上昇
3. 筋力低下
4. 内臓脂肪増加
5. 生活習慣の完全堕落

#### 表面肥満度の段階
1. 変化なし
2. 柔らかな丸み
3. 服の補正が必要
4. 明確なぽっちゃり
5. 誰が見ても肥満

### 8-5. ゲーム上の利点

- 潜伏ビルドが成立する
- 見た目の変化を遅らせて、世界全体に先に浸透できる
- 終盤に偽装を捨て、複数国で一気に表面化させる快感が生まれる

## 10. 世界側の対抗システム

#### アウレリア
- **効く偽装**：コルセット、補正下着、宮廷幻影、豊満美の社交界流行
- **発覚トリガー**：女性騎士団の持久力低下、魔導士の検診、貴族服の寸法直し急増、舞踏会の失調
- **ゲーム上の性格**：広がるが、見つかると一気に世界が動く

#### マルシェル
- **効く偽装**：流行服、広告、ゆったり衣装、補正下着
- **発覚トリガー**：砂糖・乳脂輸入急増、港湾労働低下、大きい型紙不足、食堂売上の異常
- **ゲーム上の性格**：世界へ広げる最強の起点。発覚も早い

#### ルミナス
- **効く偽装**：法衣、清廉イメージ、私的隠蔽、断食の形骸化
- **発覚トリガー**：祈祷持久力低下、斎戒違反、法衣直し増加、治癒術師の異常報告
- **ゲーム上の性格**：太らせるより、気づかせないことが重要

#### グラウ
- **効く偽装**：隠れ脂肪、厚手衣服、がっしり体型扱い、豊作による自然増との誤認
- **発覚トリガー**：畑仕事の効率低下、収穫速度悪化、牧畜作業遅延、息切れの噂
- **ゲーム上の性格**：初心者向けの育成場。安全だが波及力は低い

#### エルディナ
- **効く偽装**：幻影魔法、美意識改変、樹皮繊維衣装、姿見操作
- **発覚トリガー**：弓術精度低下、樹上移動失敗、儀式舞踏の乱れ、長老の生命律感知
- **ゲーム上の性格**：侵入困難だが、潜伏性能が極めて高い

#### ヴァルク
- **効く偽装**：筋肉誤認、毛皮装具、ベルト、よく食べるほど強い価値観
- **発覚トリガー**：狩猟失敗、闘技成績低下、長距離移動の息切れ、訓練障害
- **ゲーム上の性格**：単なる食欲増加では倒れない。生活習慣を崩す必要がある

#### フェイリア
- **効く偽装**：幻粉、花弁衣装、祝祭陶酔、身体差の個体差扱い
- **発覚トリガー**：飛行持続低下、花蜜採集効率悪化、円舞の乱れ、妖精粉消費増加
- **ゲーム上の性格**：人口は少ないが、最後まで残りやすい

## 17. 現時点での重要判断

1. 国数は7つで固定
2. 種族は人間 / エルフ / 獣人 / 妖精の4つで固定
3. 人間国家は4つ、他種族国家は各1つ

5. 隠れ肥満は本作の中核システムとして採用
6. 勇者パーティは当面、背景設定のみ
7. 勝利時は最終的に全員肥満化する
8. 作中で主に見せるのは成人女性だが、世界全体では男女とも影響を受ける

## 19. 参考にした原作上の設計観点

- 国ごとに人口密度・富裕度・交通・研究寄与が異なり、それが攻略順を変えること
- 富裕国や重要国ほど治療研究に寄与しやすいこと
- 港や空路のある国が世界拡散の要になり、発見後は封鎖され得ること
- 症状の深刻さが高いほど政府に発見されやすくなること
- 島国や接続の少ない国が終盤の取りこぼしになりやすいこと

本作ではこれらを、**交易・文化・偽装・研究・社会的発覚**へ置き換えている。
