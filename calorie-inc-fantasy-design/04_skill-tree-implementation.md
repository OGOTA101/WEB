# Calorie Inc. - 実装用スキルツリー仕様書 v0.1

## 0. この文書の役割

本書は、`03_complete-game-spec.md` を実装データへ落とすためのスキルツリー仕様である。  
対象は 4 系統すべて。

1. 流行系《Spread》
2. 肉付き系《Manifestation》
3. 堕落系《Corruption》
4. 偽装系《Concealment》

本作は肥満化フェチ、腹肉フェチ、太り始めぽっちゃりフェチを主題の一部に置くため、  
スキルの報酬は「最終段階の肥満」だけでなく、**初期のやわらかさ、隠れた体脂肪、服越しの圧、腹部から先に変わる兆し**にも明確に配分する。

## 1. 共通数値ルール

### 1-1. 基本単位

| 用語 | 実装上の意味 |
|---|---|
| MP | 魔力ポイント。スキル購入コストに使う |
| 浸透速度 | 国ごとの浸透率上昇速度 |
| 実肥満増加 | 実肥満度の増加量 |
| 表面肥満増加 | 表面肥満度の増加量 |
| 偽装値 | 発覚度を下げる内部値 |
| 発覚度増加 | 国ごとの発覚度の進みやすさ |
| 研究速度 | 瘦身魔法《リデュース》の進行速度 |
| 文化受容 | 見えている変化を“問題”と見なさない補正 |

### 1-2. 想定する基礎値

| 項目 | 初期基準値 |
|---|---:|
| 国ごとの基礎浸透速度 | 1.00 |
| 国ごとの基礎実肥満増加 | 0.10 / 日 |
| 国ごとの基礎表面肥満増加 | 0.08 / 日 |
| 基礎発覚度増加 | 0.06 / 日 |
| 基礎研究速度 | 1.00 |

### 1-3. スタック方針

- 同カテゴリ内の倍率は原則 **加算**。
  - 例：浸透速度 +15% と +20% は合計 +35%
- 異カテゴリ同士は **乗算**。
  - 例：国補正 × スキル補正 × イベント補正
- 偽装値は発覚度計算に直接差し引く。
- 「文化受容」は、表面肥満度から生じる発覚寄与を減衰させる。
- 高Tierほど、**強い数値効果と強いビジュアル解放**を同時に持つ。

### 1-4. 進行段階の目安

#### 実肥満度
| 値 | 状態 |
|---:|---|
| 0-19 | ほぼ通常 |
| 20-39 | 体脂肪率上昇、太り始め |
| 40-59 | 隠れ肥満が成立し始める |
| 60-79 | 明確な肥満進行 |
| 80-100 | 不可逆的な堕落段階 |

#### 表面肥満度
| 値 | 状態 |
|---:|---|
| 0-14 | 外見変化ほぼなし |
| 15-29 | 頬・腰・下腹にごく軽い丸み |
| 30-44 | 服の張り、座位での腹部圧が出る |
| 45-64 | 誰が見てもぽっちゃり |
| 65-84 | 明確な肥満 |
| 85-100 | 強い体型変化 |

### 1-5. フェチ報酬レイヤー

| レイヤー | 主な魅力 | 主に担当するスキル |
|---|---|---|
| 太り始め | 頬のやわらかさ、下腹のわずかな丸み、以前より少し窮屈な衣装 | 食欲増幅、やわらかい体質、甘味の流行 |
| 隠れ肥満 | 外見はまだ保っているのに、体脂肪率・筋力が先に崩れている | 隠れ脂肪蓄積、内臓脂肪化、筋肉の脂肪置換 |
| 腹肉 | 腰回りより先に下腹が出る、座ると布越しに形が出る、コルセットへ圧がかかる | 腹部優先蓄積、補正下着の流行、コルセット文化 |
| ぽっちゃり定着 | 丸みが可愛く見える、生活の中で体型変化が自然になる | 豊満美の流行、食文化礼賛、健康体型という建前 |

# 2. 流行系《Spread》

## 2-1. 系統の役割

- 国を越えて広げる
- 序盤の選択肢を作る
- どの国からどう侵食するかを決める

## 2-2. ツリー構造

```text
甘味の流行 I
├─ 甘味の流行 II
│  └─ 宮廷グルメ
├─ 夜食文化
│  └─ 宅配使い魔
└─ 祝い菓子
   ├─ 宴会奨励
   └─ 巡礼土産

港湾流通
└─ 海上菓子便
```

# 5. 偽装系《Concealment》

## 5-1. 系統の役割

- 本作の個性を決める最重要ツリー
- 実肥満と表面肥満を分離する
- 太り始め / 隠れ肥満 / 腹肉圧迫のフェチ報酬を最も繊細に扱う

```text

│  └─ 筋肉の脂肪置換
└─ やわらかい体質

補正下着の流行
├─ コルセット文化の復権
│  └─ 貴族服飾の誇張
└─ ゆったり衣装の流行

幻影化粧

└─ 舞踏会の幻装
   └─ 集団認識改竄

記録改竄
└─ 不調の個人責任化
```

# 9. バランス上の意図

## 9-1. なぜ「隠す」スキルを強くするのか

このゲームでは、強く太らせるほど発覚が早まる。  
そのため、プレイヤーがただ肉付き系だけを取ると失敗しやすい。  
**太らせる / 隠す / 受け入れさせる** の3点を組み合わせた方が強くなるように設計する。

## 9-2. なぜ「太り始め」を長く扱うのか

フェチ的な価値は、最終体型だけではなく、

- 以前より少しだけ柔らかい
- まだ細く見えるが、衣装だけが先に変わる
- 下腹だけがわずかに主張し始める
- 本人はまだ気づいていない

という**変化の途中**に強く宿る。  
そのため、実装上も 15〜40 の中間帯にイベントと補正を厚く置く。

## 9-3. なぜ「腹部優先」をリスク付きにするのか

腹部変化は本作の象徴的報酬だが、最も見つかりやすい。  
だからこそ、

- 早く見たいなら発覚リスクを背負う
- 長く隠したいなら補正下着やコルセットへ投資する

という、**フェチ欲求そのものを戦略の葛藤に変える**。
