# Plague Inc. 研究メモ

## 1. まず抽出するべき「面白さの骨格」

Plague Inc. の本質は、病気そのものではなく、以下の 3 段階を一つの短いプレイセッションに圧縮している点にある。

1. **潜伏期**
   - まだ見つからないうちに、できるだけ多くの地域へ広げる。
   - 早い段階では派手な症状を取らず、感染力や地域適応を優先する。

2. **適応期**
   - 国ごとの気候・貧富・都市性・交通網の違いに応じて、必要な伝播手段や耐性を取る。
   - 「世界は均一ではない」という感覚が、プレイヤーの意思決定を生む。

3. **決着期**
   - 露見後は治療研究が始まり、残り時間との競争になる。
   - ここで一気に致死性を上げるか、研究妨害へ寄せるか、残った未感染地域を埋めるかの判断が問われる。

この 3 幕が、1 プレイ内で自然に立ち上がるのが重要。

---

## 2. Plague Inc. から学ぶべき主要システム

### A. 3 本の進化ツリー

| 原作の系統 | 役割 | 設計上の意味 |
|---|---|---|
| Transmission | 広がり方を変える | 序盤の選択肢を作る |
| Symptoms | 効果を強める | 露見と勝利条件を動かす |
| Abilities | 環境適応・研究妨害 | 中盤以降の補助輪ではなく、勝敗を左右する |

### B. コスト上昇の圧

- DNA は有限で、何でも取れるわけではない。
- 進化を重ねるほど他の選択肢が高くなるため、**ビルド方針**が生まれる。
- これにより「全部盛り」より「今回は空港経由重視」「寒冷地対策先行」のようなプレイ差が出る。

### C. 国の個性

各国は単なる色塗り領域ではない。

- 人口
- 密度
- 富裕度
- 都市 / 農村
- 気候
- 交通網
- 研究能力

この差があるからこそ、同じビルドでも世界地図上で詰まる場所が変わる。

### D. 人類側の反撃

- 治療研究の進行
- 国境封鎖
- 交通遮断
- 政府行動

重要なのは、世界がプレイヤーに対して**反応してくる**こと。  
プレイヤーの行動に対してニュースが返り、局面が変化するので、数値ゲームがドラマになる。

### E. 疫病タイプによる再プレイ性

原作は病原体タイプごとに挙動が違うため、同じ世界地図でも違うゲームになる。  
つまり、**マップを増やすより、勝ち筋を変える方が再プレイ性に効く**。

## 3. 本作へ持ち込むときの変換方針

| Plague Inc. | 本作への翻訳 |
|---|---|
| 感染者 | 祝福の影響下にある住民 |
| DNA | 甘露点 / 呪力 |
| 感染力 | 浸透力 |
| 重症度 | 露見度 |
| 致死性 | 変容度 / 肥満化圧 |
| 治療 | 節制の秘薬 / 聖務庁の浄化計画 |
| 伝播経路 | 食文化・流通・習俗・魔法 |
| 気候適応 | 地域嗜好・保存食文化・寒暖対応 |

### 重要な差別化

本作では、世界を滅ぼすのではなく、  
**「人々が少しずつ甘やかされ、ふくよかになり、抵抗心まで鈍っていく」**  
ことを目標にする。

だから、原作の「殺すほど勝ちに近づく」構造はそのまま持ち込まない。  
代わりに、

- どれだけ広く浸透したか
- どれだけ深く体型変化したか
- どれだけ抵抗運動を弱められたか

の 3 軸で勝利を判定する。

## 4. 借りるべきもの / 借りすぎないもの

### 借りるべき

- 3 系統ツリー
- 世界地図
- 地域特性
- 序盤潜伏 / 中盤適応 / 終盤競争
- ニュースイベントによる情勢変化
- タイプ別のルール差

### 借りすぎない方がいい

- 感染・治療という用語そのもの
- 病原体の見た目
- 人類滅亡の勝利条件
- 世界の国名や現実地理
- 原作の UI 配置をそのままなぞること

### 狙うべき立ち位置

> 「Plague Inc. に着想を得たが、遊んだ感触は  
>  “世界をゆっくり甘やかしていく魔王令嬢の戦略ゲーム” である」
