# ゲーム仕様書 v0.1

## 0. 設計思想

### コア体験

> **見つかる前に広げ、見つかった後は読み勝ち、最後に世界を甘く沈める。**

### 設計原則

1. すべての数値はプレイヤーの意思決定へつながること
2. 世界地図の変化とキャラクター変化を常に同期させること
3. “広げる” と “深める” を別の判断にすること
4. 終盤に必ず圧力を作ること
5. フェチ表現は報酬であり、ゲーム進行の副産物ではなく中核に置くこと

---

## 1. 基本ループ

```text
甘露点を得る
   ↓
能力を進化させる
   ↓
地域ごとの浸透率 / 変容度が上がる
   ↓
世界情勢が変わる
   ↓
新たな甘露点・イベント・対策が発生
   ↓
次の判断へ
```

## 4. 進化ツリー

## 4-1. 誘因系（Transmission 相当）

世界へ広げるための文化・流通・習俗の進化。

| スキル | 効果 |
|---|---|
| 焼き菓子の流行 I | 都市で浸透率上昇 |
| 屋台文化 | 農村・祝祭地域で浸透率上昇 |
| 宅配魔法便 | 都市間伝播、富裕地域に強い |
| 港町スイーツ便 | 海路伝播強化 |
| 香り風 | 乾燥地域・陸路伝播強化 |
| 夢見のレシピ | 露見を抑えつつ遠隔伝播 |
| 大祝祭連鎖 | 祝祭文化で爆発的浸透 |

### 役割

- 序盤の主戦場
- 地域差に合わせたビルド分岐
- 「どこからどう広げるか」を決める

---

## 4-2. 変容系（Symptoms 相当）

身体変化と生活習慣の深化。

| スキル | 効果 |
|---|---|
| 食欲増進 I | 変容度微増、露見度小 |
| 満腹感鈍化 | 変容度上昇 |
| 代謝緩慢 | 寒冷地域で強い |
| 甘味記憶 | 再浸透速度上昇 |
| 腹部蓄積 | 代表ヒロインの腹部差分解放 |
| 安楽志向 | 抵抗意志低下 |
| ふくよかな多幸感 | 変容度大幅上昇、露見度も大 |

### 役割

- 勝利に必要な“深さ”を作る
- キャラクター差分の主要トリガー
- 露見とのトレードオフを生む

---

## 4-3. 支配系（Abilities 相当）

地域適応、対策妨害、特殊行動。

| スキル | 効果 |
|---|---|
| 寒冷地保存術 | 寒冷地域適応 |
| 乾燥地糖蜜術 | 乾燥地域適応 |
| 富裕層献上品 | 富裕地域の抵抗を下げる |
| 修道院寄進 | 禁欲地域の露見速度低下 |
| 書庫の甘い虫食い | 浄化研究遅延 |
| 甘夢干渉 | 特定地域の対策を一時停止 |
| 宴席召喚 | 任意地域へ一時的な大浸透 |

### 役割

- 中盤以降の詰まりを解消
- 研究や抵抗への反撃
- “世界と戦っている” 感触を作る

## 5. 代表ヒロインシステム

### 目的

国の数値変化を、感情的に見える形へ変換する。

### 1 キャラあたりの状態段階

| 段階 | 内容 |
|---|---|
| 0 | 通常 |
| 1 | 食欲増加の兆し |
| 2 | 頬・腰回りに変化 |
| 3 | 腹部の存在感が明確化 |
| 4 | 衣装や所作に変化 |
| 5 | 価値観の受容 / 専用イベント |

### 解放条件例

- 地域浸透率 20 / 40 / 60 / 80%
- 地域変容度 15 / 35 / 55 / 75
- 特定スキル取得
- 特定イベント通過

### 表現方針

- 全キャラクターは成人女性
- 変化は嘲笑ではなく、嗜好性とキャラ魅力を保って描く
- フェチ表現は局所ではなく、会話・衣装・立ち姿・日常の変化まで含める

## 6. 世界側の対抗システム

## 6-1. 露見フェーズ

| フェーズ | 状態 |
|---|---|
| 0 | 誰も異変に気づいていない |
| 1 | 地方紙が食欲増加を報道 |
| 2 | 聖務庁が調査開始 |
| 3 | 各国が節制勧告 |
| 4 | 浄化研究本格化 |
| 5 | 反動運動・物流規制 |

## 6-2. 対策イベント

| 対策 | 効果 |
|---|---|
| 断食令 | 禁欲地域の浸透率低下 |
| 祝祭自粛 | 祝祭文化へのボーナス無効化 |
| 馬車検問 | 陸路伝播低下 |
| 港湾検疫 | 海路伝播低下 |
| 聖油配布 | 変容度上昇を抑制 |
| 浄化秘薬研究 | 敗北時計を進める |

## 6-3. プレイヤー側の対抗策

- 研究遅延
- 露見抑制
- 反動運動の支持率低下
- 文化化による「対策しても戻らない」状態の形成

## 10. バランス設計の基本式

### 地域の 1 ターン変化

```text
浸透増加 =
  基礎浸透力
  × 地域適性補正
  × 交通補正
  × 文化補正
  × 対策補正

変容増加 =
  現在浸透率
  × 変容系スキル補正
  × 地域受容補正
  × 対策補正
```

### 露見度

```text
露見度増加 =
  変容度
  + 派手なイベント
  + 一部スキルの副作用
  - 潜伏系支配スキル
```

### 設計意図

- 浸透率だけ高くても勝てない
- 変容度だけ上げても早く見つかる
- だからプレイヤーは、広げる / 深める / 隠す を常に配分する
