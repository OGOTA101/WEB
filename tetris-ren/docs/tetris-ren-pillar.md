# TETRIS // REN - Pillar Contract

## Intent

- テトリミノを落として列を消し、RENを伸ばす短時間アーケードゲーム。
- ラインを消した直後の大きなREN表示と、連続消去の勢いを気持ちよく伝える。
- 固定後の列落下で縦の空白を残さない、少し変わった重力ルールを主役にする。
- キーボードでもタッチでも、最初の一手まで迷わず遊べる。

## Core Fun

積み上げた形をきれいに消し、次の一手でRENをつなげる読み合いが中心。空白が残らない列重力によって、普通のテトリスとは違う崩れ方とリカバリーが起きる。

## Pillars

### ren-momentum
ライン消去が続くほどRENが上がり、スコア倍率と画面演出が強くなる。

### no-hole-gravity
固定後は各列のブロックが下へ詰まり、縦方向の空白を残さない。落下先が空いていれば、そこまで自然に落ちる。

### arcade-clarity
盤面を主役に、NEXT、スコア、レベル、操作を最小HUDへまとめ、PCとスマホで重要な変化だけを読ませる。

## Core Loop

- テトリミノを左右移動・回転・落下させる。
- 空白のある最下位置まで落として固定する。
- 列重力でブロックを詰め、そろったラインを消す。
- RENとスコアを加算し、演出で連続性を知らせる。
- 次のピースを受け取り、盤面が埋まるまで続ける。

## Art Direction

Vanilla HTML Canvas + CSSで作る、レトロフューチャーなアーケードUI。黒に近いインク色を土台に、ライム、オレンジ、シアンを盤面の発光アクセントとして使う。暗い背景の中で、RENだけが大きく跳ねる。

## Modules

### board-simulation
- Carries: 盤面、衝突判定、列重力、ライン消去、ゲームオーバー判定。
- Watch-out: 列重力を通常のテトリスの自然落下と混同しない。固定後に必ず全列を圧縮する。

### piece-control
- Carries: 7-bag、NEXT、回転、左右移動、ソフト／ハードドロップ、キーボード、盤面タップ、スマホボタン入力。上キー／SPACE／スマホの下スワイプで即落下、スマホの上スワイプで回転する。
- Watch-out: 回転時の壁際で操作不能にならないよう、少数のキック候補を試す。

### arcade-feedback
- Carries: スコア、レベル、REN、ライン数、発光、消去フラッシュ、操作パネル。
- Watch-out: 派手さで盤面を隠さず、数字の更新は常に読める状態にする。
