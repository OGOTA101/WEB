# ルーレットいかさまアイデア100

## 読み方

- 通常時の土台は、0〜36のヨーロピアンルーレット、実際の番号順、実際の赤黒、実際の賭け配当
- 以下の案は通常ルールを置き換えるものではなく、魔法で一時的に結果・物理・監視・配当を壊す「いかさま」
- 37、全ポケット7、10ボールなど、現実にない状態はすべて魔法発動中だけ存在する
- **魔力**：目安コスト。低＝1〜2、中＝3〜4、高＝5〜8
- **警戒**：成功しても上がる警戒圧の目安。実装時の警戒度は0〜10で管理する
- 警戒圧の正規化は、表の `+1〜+4` を警戒度+1、`+5〜+10` を+2、`+11以上` を+3の目安にする。同じいかさまIDを直近3スピン以内に再使用した場合は、さらに+2、3回目以降は+4を加える
- 警戒度が10になった場合は、3回の通常スピンを完了するまで全魔法をロックする
- 見られずに効果が成立した案は、勝敗に関係なく成功いかさま回数を+1し、熟練度による魔法解禁へつながる
- **危険**：詠唱の長さ、痕跡、対象の大きさを合わせた「見られやすさ」
- 発動中に視線へ入った場合、危険度に関係なくGame Over
- 100案は全部を同時に入れるものではなく、MVP後の追加候補を含む発想バンク

## 使い分けのサンプル

### 低コストで静かに勝つ

`1 黒を赤に染める` → `41 ディーラーをくしゃみさせる` → `89 くしゃみやウインクを詠唱にする`

小さな魔法をつなげる代わりに、盤面とディーラーの視線を両方読む。初心者向けの「安全時間を覚える」構成。

### 警戒を受け入れて一気に返す

`29 バウンドの瞬間に分裂する` → `75 配当をボール数倍にする` → `62 外れたボールだけ爆破する`

ボール数と配当を増やし、外れだけを爆破する。成功しても警戒度が高くなり、次のスピンを冷却に使う必要がある。

### 検知器を逆手に取る

`33 検知ログを1秒遅らせる` → `39 画面を二重化する` → `79 検知器の警戒度へ賭ける`

検知器の情報そのものを読み替える構成。盤面を見ずに音と波形でプレイする上級者向け。

### 終盤の無茶

`91 10個のボールに投票させる`、`92 2台目のルーレットを召喚する`、`100 カジノ全体を巨大ルーレットにする`

勝率を上げるというより、画面と物理を崩して「この卓はもう普通のルーレットではない」と感じさせるための大技。使うほど検知器の表示も壊れていく。
