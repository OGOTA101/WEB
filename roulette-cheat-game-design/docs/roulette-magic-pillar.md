# Magic Roulette - Pillar Contract

## Intent

- 実際のヨーロピアンルーレットを3Dで回し、結果が止まってからも3秒だけ逆転を狙える
- 画面を見た瞬間に、赤・黒・数字のどこへ賭けて、どこを押せば回るかがわかる
- 球の投入、外周走行、減速、内周への落下、ポケット停止までを一続きの3D挙動として見せる
- 画面端の杖をルーレット中央へドラッグするなど、魔法の操作そのものが手品になる
- 見られずにいかさまを成功させるほど熟練度が上がり、より無茶な魔法が増える
- 同じ魔法の使い回しで警戒度が上がり、10になると普通のルーレットだけで冷却する
- 1,000円を1億円へ増やす、短いが何度も挑戦できるゲームループ

## Core Fun

大きな赤・黒ボタンか数字を選んで回し、球が実際に外周からポケットへ落ちる瞬間を見届ける。「今の数字は外れた」と思ったら、杖を中央ピンへ滑らせて結果を吹き飛ばす。

## Pillars

### physical-cheating

魔法はボタンだけでなく、なぞる、つかむ、ドラッグする、ホールドするという画面上の手品として表現する。操作が成立した瞬間に、ルーレットの物理と結果へ作用する。

### readable-risk

検知器の安全時間、警戒度0〜10、同じ魔法の再使用ペナルティを明確に表示する。強い魔法ほど結果は変わるが、見られる時間と警戒ロックへ近づく。

### growing-arsenal

見られずに成功したいかさま回数で魔法を解禁する。最初は直感操作、後半は複数対象や長いホールドを要求し、熟練している感覚を操作の難度でも伝える。

### real-roulette-goal

盤面、番号順、赤黒、配当は通常時は実際のヨーロピアンルーレットに合わせる。通常の負けはGame Overではなく、1,000円から1億円までの資金曲線を作る。

## Core Loop

- 下段の賭け盤にチップを置く
- 上段の3Dルーレットを回し、検知器で安全時間を読む
- 走行中または結果停止後3秒の保留中に、魔法を直感操作する
- 見られずに結果を改竄するか、外れを受け入れて通常配当を確定する
- 所持金、警戒度、魔力、成功いかさま回数を更新する
- 新しい魔法を解禁し、次のスピンでさらに大きな賭けを試す

## Art Direction

Three.js + TypeScript + ViteによるWeb 3D。上段の大きな3D盤面と下段の操作だけに絞り、荒いローポリ、黒い背景、煤けた緑のフェルト、真鍮、赤い警告光で独自の地下カジノを作る。装飾パネルや常時ログは減らし、球と赤黒ボタンを最も目立たせる。

## Modules

### roulette-simulation

- Carries: 0〜36の通常結果、実際の赤黒と配当、外周壁・固定ピン・回転仕切りとの固定刻み衝突、3Dホイールとボールの進行、3秒RESULT_PENDING
- Watch-out: 見た目の物理と確定結果を混ぜず、テストしやすい結果モデルを先に持つ

### cheat-system

- Carries: 魔法の入力、結果改竄、警戒度、同じいかさまIDの再使用、爆発リセット
- Watch-out: すべての魔法を同じクリックにせず、初期魔法の手触りを守る

### skill-progression

- Carries: 成功いかさま回数、熟練ランク、魔法解禁、操作ヒント
- Watch-out: 解禁が速すぎて大技だけになると、通常ルーレットと警戒ロックの意味が消える

### casino-ui

- Carries: 上下分割レイアウト、大きな赤黒ベット、折りたためる数字盤、所持金、警戒度、検知器、魔法トレイ、BET→START→STOP→ROUND ENDの結果演出
- Watch-out: 状態・監視・魔法を別々の大型パネルにせず、3D盤面と賭け操作の視線を分断しない
