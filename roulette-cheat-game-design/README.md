# ルーレットいかさまゲーム

荒っぽいローポリの地下カジノで、女の子の魔法使いが実際のルーレットを魔法で無茶苦茶に改竄する、遊べるWeb 3Dゲームです。

```powershell
npm install
npm run dev
```

## ファイル

- [ゲーム仕様書.md](./ゲーム仕様書.md) — 企画の核、ルール、画面、演出、MVP、検証条件
- [いかさまアイデア100.md](./いかさまアイデア100.md) — ボール・盤面・時間・カメラ・観客・魔法・大技に分けた100案

## 企画の一行説明

**「1,000円を1億円にするまで、見られていない0.5秒で本物のルーレットを魔法で壊す」**

## まず作る範囲

1. 実際のヨーロピアンルーレット1台と、球の投入・外周壁／固定ピン／ポケット仕切りへの衝突・ポケット落下
2. 上段の大きな3Dルーレットと、下段の大きな赤・黒ベットボタン
3. 折りたたみ式の0〜36数字盤
4. いかさま検知器が示す安全時間と監視時間
5. 同じ魔法の使い回しで警戒度が急上昇し、10で全魔法がロックされる仕組み
6. 成功いかさま回数で熟練度が上がり、直感操作の魔法から順に解禁される仕組み
7. 結果停止後3秒の保留と、杖を中央ピンへ2秒ドラッグする爆発リセット
8. 色変更・数字変更・爆発リセット・ボール増殖を含む12魔法
9. 所持金1,000円から1億円を目指す短時間プレイ
10. BET PLACED → START → STOP → ROUND END（WIN／LOSE）が一目で追えるラウンド演出

100案はすべてを同時に実装するリストではなく、MVP後に「このゲームらしい無茶」を追加するための発想バンクです。
