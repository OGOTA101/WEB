# 仕様書: 60秒防衛線 (60-Second Defense Line) - ゲーム設計書

本文書は、新規ゲーム「60秒防衛線」の設計仕様書である。

---

## 1. プロジェクト概要

### コンセプト
**「過去の自分と協力して、60秒の防衛戦を生き延びろ！」**

プレイヤーは猫を操作し、弾薬庫から砲弾を回収して3つの大砲に装填・発射する。
画面上から3つのラインを通ってゆっくり進軍するネズミたちを、ゆっくり飛ぶ砲弾で迎え撃つ。

**最大の特徴は「タイムループ協力システム」**。
失敗しても、過去の自分の動きが「ゴースト猫」として次のプレイに登場！
最大3匹の猫（自分 + ゴースト2匹）で協力して、不可能を可能にする。

**移動と停止だけ**のシンプル操作で、戦略的な防衛を楽しむゲーム。

### ゲームの特徴
- **タイムループ協力**: 過去の自分（ゴースト猫）と一緒に戦える！（Cursor*10風）
- **シンプル操作**: タップで移動、止まるだけで自動アクション
- **戦略性**: 3つのラインと3つの大砲、どこを優先するか判断
- **ゆっくりペース**: 弾丸もネズミもゆっくり、考えながらプレイ
- **運搬アクション**: 弾薬庫 → 大砲の往復が楽しいコアループ
- **リプレイ性**: 過去の自分の動きを活かして何度でも挑戦

### デザインテイスト
- **ドット絵スタイル**: RPGツクールのようなピクセルアート
- **視点**: トップダウン（真上から見下ろし）
- すべてのグラフィックはドット絵で統一
- レトロゲーム風の親しみやすいビジュアル

### ターゲットプラットフォーム
- **Webブラウザ** (Mobile First, PC Compatible)
- **Viewport**: 9:16 (縦長) 固定。PCでは左右に黒帯を表示。

### ゲームペース
- **ゆっくりプレイ**: スマホ縦画面のため、すべてがスローペース
- 考えながらプレイできる戦略性重視のゲームテンポ
- 制限時間は60秒（ゲーム名の由来）

## 2. グラフィック仕様

### サイズ規定
- **最大スプライトサイズ**: 128×128ピクセル
- オブジェクトごとに個別の画像ファイルとして用意
- **視点**: トップダウン（真上から見下ろし / 俯瞰視点）

### 透過処理仕様 ⚠️ 重要
| 項目 | 値 |
|:-----|:---|
| **背景色** | 純黒 `#000000` (RGB: 0, 0, 0) |
| **透過方式** | クロマキー方式（黒色抜き） |
| **透過処理** | JavaScriptで黒ピクセルを透過に置換 |

**理由**: PNG透過アルファチャンネルではなく、黒を透過色として使用することで、
レトロゲーム風の明確なエッジを維持し、ファイルサイズも軽量化。

**実装方法**:
```javascript
// Canvas で黒色を透過に変換する関数
function applyBlackTransparency(image) {
  const canvas = document.createElement('canvas');
  canvas.width = image.width;
  canvas.height = image.height;
  const ctx = canvas.getContext('2d');
  ctx.drawImage(image, 0, 0);
  
  const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
  const data = imageData.data;
  
  for (let i = 0; i < data.length; i += 4) {
    // 純黒 (R=0, G=0, B=0) を透過に
    if (data[i] === 0 && data[i+1] === 0 && data[i+2] === 0) {
      data[i+3] = 0; // アルファを0に
    }
  }
  
  ctx.putImageData(imageData, 0, 0);
  return canvas;
}
```

**アセット作成ルール**:
1. すべてのスプライトは**黒背景 (#000000)** で作成
2. キャラクター/オブジェクト自体に純黒を使わない（#010101 等で代用）
3. RPGツクール風のクリーンなドット絵
4. アンチエイリアスなし（ピクセルがはっきり見える）

## 4. ゲームメカニクス

### 4.1 プレイヤー操作（猫）

#### 移動
| 操作 | 動作 |
|:-----|:-----|
| 画面タップ | タップした位置へ猫がゆっくり移動 |
| 移動中断 | 現在位置でタップすると停止 |

#### 移動制限
- 猫は**画面下1/3のエリア**のみ移動可能
- 3つの大砲と弾薬庫がこのエリア内に配置

#### 猫の状態
| 状態 | 説明 |
|:-----|:-----|
| 待機 | 何も持っていない、静止状態 |
| 移動中 | タップ位置へ向かって歩行中 |
| 砲弾運搬中 | 砲弾を持っている状態 |
| アクション中 | 回収/装填/発射の実行中 |

#### 猫のアニメーション
- 4方向 × 2フレーム歩行アニメーション
- 最後に移動した方向を向いて静止
- 砲弾運搬時は砲弾を持っているオーバーレイ表示

### 4.2 エリアシステム（自動アクション）

猫が特定のエリアに**一定時間滞在**すると、自動でアクションが実行される。

#### 弾薬庫エリア
| 項目 | 値 |
|:-----|:---|
| 必要滞在時間 | 1.0秒 |
| 条件 | 砲弾を持っていない |
| 効果 | デッキからランダムで砲弾1つを回収 |
| 視覚表現 | 回収ゲージ表示、完了時エフェクト |

#### 装填エリア（大砲の後ろ）
| 項目 | 値 |
|:-----|:---|
| 必要滞在時間 | 1.5秒 |
| 条件 | 砲弾を持っている & 大砲が空 |
| 効果 | 持っている砲弾を大砲に装填 |
| 視覚表現 | 装填ゲージ表示、完了時エフェクト |

#### 発射エリア（大砲の横）
| 項目 | 値 |
|:-----|:---|
| 必要滞在時間 | 0.5秒 |
| 条件 | 大砲に砲弾が装填済み |
| 効果 | 大砲を発射、砲弾が上方向へ飛ぶ |
| 視覚表現 | 発射ゲージ表示、発射時エフェクト |

```
アクションフロー:

弾薬庫で滞在 → 砲弾回収 → 大砲後ろで滞在 → 装填 → 大砲横で滞在 → 発射！
    (1秒)                      (1.5秒)              (0.5秒)
```

### 4.6 敵システム（ネズミ）

5. 倒されるまで攻撃継続

|:---|:-----|:---|:-----|:-------|:-----|

| `armored` | 装甲ネズミ | 3 | 80% | 1 | 硬い |
| `fast` | 速いネズミ | 1 | 200% | 1 | 速い |
| `big` | 大きいネズミ | 5 | 60% | 2 | 強力 |

#### 攻撃パラメータ
| 項目 | 値 |
|:-----|:---|
| 攻撃間隔 | 2秒 |
| 攻撃対象 | 防衛力（全体共通） |

#### 防衛力
| 項目 | 値 |
|:-----|:---|

| 最大値 | 10 |
| 回復 | なし（ウェーブ間も回復しない） |

防衛力ダメージ = ネズミ攻撃力 × 攻撃回数

### 4.8 タイムループシステム（ゴースト協力プレイ）⭐ 核心システム

このゲームの**最も重要な特徴**。過去の自分と協力して防衛する「タイムループ」システム。

#### コンセプト
**「過去の自分が味方になる」**

ゲームに失敗しても、その時の自分の動きが「ゴースト猫」として次のプレイに登場。
過去の自分と一緒に防衛することで、1人では不可能だった防衛が可能になる。

名作ゲーム「Cursor*10」のような、**過去の自分との協力プレイ**を実現。

#### 猫の残機システム

| 項目 | 値 |
|:-----|:---|
| 初期残機 | 3匹（初回プレイ + 2回分のリトライ） |
| 表示 | 画面右上に猫アイコン × 残り数 |

```
残機表示:
  🐱🐱🐱  ← 初期状態（3匹）
  🐱🐱    ← 1回リロード後（2匹）
  🐱      ← 2回リロード後（1匹、最後の猫）
```

#### リロードボタン

| 項目 | 説明 |
|:-----|:-----|
| 位置 | 画面右上（ポーズボタンの隣） |
| アイコン | 🔄 リロードマーク |
| 押下条件 | 残機が2匹以上ある時のみ有効 |
| 効果 | ゲームを最初（Wave 1の0秒）からやり直す |
| コスト | 猫を1匹消費 |

#### リロード時の挙動

```
リロードボタン押下:
  1. 現在までの自分の行動を記録完了
  2. 猫残機を1減らす
  3. ゲームをWave 1の0秒にリセット
  4. 全ての敵・砲弾をリセット
  5. 防衛力を初期値（10）にリセット
  6. 大砲の装填状態をリセット
  7. 過去の自分が「ゴースト猫」として登場
  8. 新しいプレイ開始
```

#### ゴースト猫（過去の自分）

| 項目 | 説明 |
|:-----|:-----|
| 見た目 | **青白く半透明**な猫（幽霊のような外観） |
| 動き | 過去のプレイを**完全に再現** |
| アクション | 砲弾回収、装填、発射を**実際に実行** |
| 当たり判定 | なし（プレイヤー猫と重なっても問題なし） |
| 数 | 最大2匹（過去1回目、過去2回目のゴースト） |

#### ゴースト猫の行動

ゴースト猫は過去のプレイを**完全再現**し、以下のアクションを**実際に実行**する：

| アクション | ゴーストの挙動 |
|:-----------|:---------------|
| 移動 | 過去と同じルートで移動 |
| 砲弾回収 | 弾薬庫で砲弾を回収（デッキから取得） |
| 装填 | 大砲に砲弾を装填 |
| 発射 | 大砲を発射、砲弾が飛ぶ |

**重要**: ゴースト猫のアクションは**ゲームに実際に影響を与える**。
プレイヤー猫とゴースト猫が協力して、同時に複数の大砲を操作できる。

#### リソースの共有と競合

| リソース | 共有/競合 | 説明 |
|:---------|:----------|:-----|
| 弾薬庫 | 共有 | どの猫でも回収可能、無限供給 |
| 大砲 | 競合 | 既に装填済みなら装填不可 |
| 発射 | 競合 | 既に空なら発射不可 |
| 防衛力 | 共有 | 全猫で共通、ダメージも共通 |

**競合時の挙動**:
- ゴースト猫が装填しようとしたが、既に装填済み → アクション失敗（スキップ）
- ゴースト猫が発射しようとしたが、既に空 → アクション失敗（スキップ）

#### 行動記録データ

プレイ中、以下の情報を時系列で記録：

```javascript
// 行動記録の構造
{
  "playId": 1,  // 何回目のプレイか
  "actions": [
    { "time": 0, "type": "move", "x": 150, "y": 500 },
    { "time": 500, "type": "move", "x": 200, "y": 480 },
    { "time": 1000, "type": "stop", "x": 200, "y": 480 },
    { "time": 2000, "type": "pickup", "shell": "normal" },
    { "time": 2500, "type": "move", "x": 100, "y": 400 },
    { "time": 4000, "type": "load", "cannon": "left", "shell": "normal" },
    { "time": 4500, "type": "move", "x": 80, "y": 400 },
    { "time": 5000, "type": "fire", "cannon": "left" },
    // ... 続く
  ],
  "endTime": 45000,  // このプレイが終了した時刻（ミリ秒）
  "endReason": "reload"  // "reload" | "death" | "clear"
}
```

#### 記録終了タイミング

| 終了理由 | 記録される時点 |
|:---------|:---------------|
| リロード | リロードボタンを押した瞬間まで |
| 死亡（防衛力0） | 防衛力が0になった瞬間まで |
| クリア | 全ウェーブクリアまで（使用しない） |

#### ゲームオーバー条件（タイムループ版）

**全ての猫が使われた状態で防衛力が0になるとゲームオーバー**

```
ゲームオーバー判定:
  IF 防衛力 == 0:
    IF 残機 >= 2:
      → 自動的にリロード可能（続行可能）
    ELSE:
      → ゲームオーバー（全猫消費済み）
```

**補足**: 最後の1匹（残機1）でプレイ中に防衛力が0になると即ゲームオーバー。

#### タイムループ可視化

| 要素 | 表示 |
|:-----|:-----|
| 現在のプレイヤー猫 | 通常のカラー、完全不透明 |
| ゴースト猫（1回目） | 青白く半透明（60%透明度） |
| ゴースト猫（2回目） | さらに薄い青白（40%透明度） |
| 残機表示 | 右上に猫アイコン |
| リロードボタン | 右上、残機2以上で有効 |

#### 協力プレイの例

```
【シナリオ: 3レーン同時攻撃に対応】

1回目のプレイ:
  - 左レーンの大砲だけ担当
  - 右レーンのネズミに突破される → 防衛力低下
  - リロードボタン押下

2回目のプレイ:
  - ゴースト猫(1)が左レーンを担当してくれる
  - 自分は中央レーンを担当
  - 右レーンのネズミにまだ対応できない → リロード

3回目のプレイ（最後の猫）:
  - ゴースト猫(1)が左レーン担当
  - ゴースト猫(2)が中央レーン担当
  - 自分は右レーンを担当
  - 全レーン対応可能！ → クリア目指す
```

## 5. ウェーブシステム

### ウェーブ構成
| Wave | 制限時間 | 敵数 | 出現ネズミ | 備考 |
|:-----|:---------|:-----|:-----------|:-----|
| 1 | 60秒 | 6体 | 通常のみ | チュートリアル的 |
| 2 | 60秒 | 10体 | 通常、装甲、速い | 本格戦 |
| 3 | 60秒 | 15体 | 全種類 | 最終波 |

### ウェーブ間
- 5秒間のインターバル
- 次ウェーブの予告表示
- 防衛力は回復しない（継続）

### クリア条件
- 全3ウェーブをクリア
- 各ウェーブ: 全ネズミ撃破 または 時間切れで敵が残っていない

### 敵スポーンパターン
```
Wave 1 (初心者向け):
  - 0秒: 左レーン 通常×1
  - 10秒: 中央レーン 通常×1
  - 20秒: 右レーン 通常×1
  - 30秒: 左・右レーン 通常×1ずつ
  - 45秒: 全レーン 通常×1ずつ（計3体）

Wave 2 (中級):
  - 混合パターン、2レーン同時など

Wave 3 (上級):
  - 全レーン同時、ボス級出現
```

### インゲームUI要素

- 各エリア（弾薬庫、装填、発射）を**薄い色のゾーン**で表示
- 猫がエリア内にいる時、ゾーンが**ハイライト**
- アクション進行中は**ゲージ表示**

### フィードバック
| アクション | フィードバック |
|:-----------|:---------------|
| 砲弾回収成功 | SE再生、エフェクト、砲弾アイコン表示 |
| 装填成功 | SE再生、エフェクト、大砲に砲弾表示 |
| 発射成功 | SE再生、大砲エフェクト、砲弾飛行開始 |
| 敵撃破 | SE再生、撃破エフェクト、敵消滅 |
| ダメージ | SE再生、画面揺れ、HP減少表示 |
