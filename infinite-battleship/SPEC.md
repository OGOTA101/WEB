# 無限航行戦艦ゲーム 仕様書

作成日: 2026-04-26  
仮タイトル: **鋼海前線 / Infinite Battleship**  
ジャンル: 縦画面協力ローグライト戦艦アクション  
想定環境: スマホ優先のブラウザゲーム、PCでもプレイ可能  
最大人数: 1-10人  

## 1. ゲーム概要

プレイヤーたちは巨大戦艦の10個の操作席を担当し、ひたすら前方へ進み続ける。  
敵は前方だけでなく左右からも出現し、時間と進行距離に応じてどんどん強くなる。一定時間ごとにボスが出現し、撃破すると5択の強化アイテムを選べる。

戦艦には全体HPと部位HPがあり、被弾した場所に近い席や武装が壊れる。壊れた席に座っているプレイヤーは移動できなくなり、タップ連打で必死に修理する。ソロプレイでは自分以外の席は自動操縦、マルチプレイでは空席のみ自動操縦になる。

プレイで得たスコアはそのままお金として持ち帰り、ガチャで初期強化パーツを入手する。1回の出撃に持ち込める強化はチーム全体で最大10個まで。

## 2. コンセプト

### 2.1 プレイヤー体験

- 巨大戦艦をみんなで動かしている感覚を出す。
- 1人でも10人分の艦を回している忙しさを楽しめる。
- マルチでは「誰がどの席に座るか」「どこが壊れたか」で自然に会話が生まれる。
- ボス撃破ごとの5択強化で、毎回違う戦艦ビルドになる。
- スコアをお金として持ち帰り、次の出撃前のガチャと持ち込み編成につなげる。

### 2.2 プレイの流れ

1. ホーム画面で即開始またはルームマッチを選ぶ。
2. 出撃前に持ち込み強化を選ぶ。
3. 戦艦が自動で前進し続ける。
4. プレイヤーは座席を移動しながら、移動、砲撃、防衛、魚雷、修理を担当する。
5. 敵を倒し、進行度とスコアを少しずつ伸ばす。
6. 一定時間ごとにボスが出現する。
7. ボス撃破で5択強化を選ぶ。
8. さらに強い敵が出る海域へ進む。
9. 戦艦全体HPが0になると終了。
10. スコアをお金として持ち帰り、ガチャや強化管理に戻る。

## 3. 対応プレイモード

### 3.1 ソロプレイ

- プレイヤーは10席のどこにでも自由に移動できる。
- プレイヤーが座っていない席はAIが自動操作する。
- 壊れた席に座っている場合、その席を修理するまで移動不可。
- ソロ時は持ち込み強化を10個すべて自分で選べる。

### 3.2 即開始

- すぐにマッチングを開始するモード。
- 最大10人まで参加可能。
- 目標待機時間は15-30秒。
- 人数が10人未満でも開始でき、空席はAIが担当する。
- 途中参加は基本なし。将来的には観戦または次航海予約として扱う。

### 3.3 ルームマッチ

- ルームコードで参加するプライベートマッチ。
- 最大10人。
- ロビーで参加者一覧、座席希望、持ち込み強化、準備OKを表示する。
- 全員が参加OKを押すと開始する。
- ホストはメンバーの未準備状態を確認できるが、強制開始は初期仕様ではなし。
- 回線落ちしたプレイヤーは30秒間復帰枠として保持する。復帰までその席はAIが担当する。

## 4. 画面構成

### 4.1 縦長スマホ基本レイアウト

画面比率は9:16を基準にする。

- 上部: スコア、進行度、戦艦全体HP、ボス出現タイマー、海域危険度
- 左側: 戦艦UI、座席移動パネル、部位HP、座席占有状態
- 右側: プレイ画面、敵、弾、ボス、操作UI

### 4.2 推奨比率

- 上部HUD: 高さ12-15%
- 下部メイン領域: 高さ85-88%
- 左の戦艦UI: 幅30-34%
- 右のプレイ領域: 幅66-70%

### 4.3 上部HUD

表示項目:

- スコア
- 持ち帰り予定のお金
- 進行距離
- 経過時間
- 現在海域レベル
- ボスまでの残り時間
- 戦艦全体HPバー
- 警報状態

例:

```text
SCORE 001240   MONEY +001240
距離 3.2km   海域 Lv.7   BOSS 00:42
SHIP HP 72%
```

### 4.4 左側の戦艦UI

荒野行動の座席移動のように、戦艦の簡易見取り図を表示する。

各席は以下の状態を持つ。

- 空席
- 自分が着席中
- 他プレイヤーが着席中
- AI操縦中
- 破損中
- 修理中
- ロック中

オンライン時:

- 他プレイヤーが座っている席は埋まって表示され、移動できない。
- 空席またはAI席には移動できる。
- 壊れている席には移動できない。
- 自分の座席が壊れた場合、修理完了まで移動できない。

ソロ時:

- 自分は壊れていない席なら自由に移動できる。
- 自分が離れた席はAIが担当する。

### 4.5 右側のプレイ画面

- 戦艦は画面中央からやや下に配置。
- 海は常に下から上へ流れ、前進感を出す。
- 敵は前方、左右、斜め方向から出現。
- 操作UIは現在座っている席に応じて変化する。
- 弾幕、爆発、魚雷航跡、修理火花、浸水演出を見やすく表示する。

## 5. 座席仕様

座席は10個。全席に最低1つ以上の操作ボタンを持たせる。

### 5.1 座席一覧

| No | 座席名 | 役割 | 主な操作 |
|---:|---|---|---|
| 1 | 艦橋 | 戦艦の位置操作、前方武器 | アナログ移動、前方砲撃、緊急回避 |
| 2 | 左主砲 | 高火力砲撃 | 方向指定、装填、発射 |
| 3 | 右主砲 | 高火力砲撃 | 方向指定、装填、発射 |
| 4 | 左副砲 | 中火力連射 | 方向指定、連射、狙撃 |
| 5 | 右副砲 | 中火力連射 | 方向指定、連射、狙撃 |
| 6 | 前左機銃 | 近距離防空、防ミサイル | 掃射、迎撃、冷却 |
| 7 | 前右機銃 | 近距離防空、防ミサイル | 掃射、迎撃、冷却 |
| 8 | 後左機銃 | 側面と後方防衛 | 掃射、迎撃、煙幕 |
| 9 | 後右機銃 | 側面と後方防衛 | 掃射、迎撃、煙幕 |
| 10 | 魚雷管制室 | 魚雷、機雷、対ボス火力 | 方向指定、魚雷発射、機雷投下 |

### 5.2 艦橋

役割:

- 戦艦全体の位置を操作する中心席。
- 敵弾、機雷、突進敵を避ける。
- 前方への基本武器も担当する。

操作:

- アナログスティック: 戦艦の左右上下移動
- 前方砲撃ボタン: 前方向に小型砲を撃つ
- 緊急回避ボタン: 短距離ダッシュ。クールダウンあり

破損時:

- 船の移動速度が大幅低下。
- アナログ操作が効かなくなる。
- 艦橋席のプレイヤーは修理完了まで移動不可。

AI操作:

- 敵弾の密度が低い方向へゆっくり回避する。
- ボス中は画面中央下を維持しやすい。

### 5.3 左主砲 / 右主砲

役割:

- 高HP敵、ボス、装甲艦への主力ダメージ。
- 連射は遅いが一撃が重い。

操作:

- 方向指定: 前方、斜め前、横方向を切り替える。
- 装填ボタン: 長押しでチャージ。最大チャージで貫通弾。
- 発射ボタン: 指定方向へ主砲発射。

破損時:

- 対応する主砲が撃てなくなる。
- 部位HPが30%以下では装填時間が長くなる。

AI操作:

- HPが高い敵またはボスの弱点を優先して撃つ。
- チャージしすぎず、基本は中チャージで発射する。

### 5.4 左副砲 / 右副砲

役割:

- 中型敵、横から来る敵への対応。
- 主砲より軽く、機銃より射程が長い。

操作:

- 方向指定: 前方、横、斜め後ろまで指定可能。
- 連射ボタン: 押している間、一定間隔で射撃。
- 狙撃ボタン: クールダウン付きの高精度弾。

破損時:

- 連射不能。
- 低HP時は弾が左右にブレる。

AI操作:

- 近づく中型敵を優先。
- 左副砲は左側、右副砲は右側を優先する。

### 5.5 前左機銃 / 前右機銃 / 後左機銃 / 後右機銃

役割:

- 小型敵、ミサイル、ドローン、魚雷を迎撃する。
- 近距離の弾幕を薄くする防衛担当。

操作:

- 掃射ボタン: 担当範囲を扇状に射撃。
- 迎撃ボタン: 最も近い飛翔物をロックして集中射撃。
- 冷却ボタン: オーバーヒートを早く解除する。
- 後部機銃のみ煙幕ボタンを持つ。煙幕は横からの敵弾命中率を下げる。

破損時:

- 対応範囲の防衛が弱くなる。
- ミサイルや魚雷を受けやすくなる。

AI操作:

- 迎撃対象がある場合は迎撃優先。
- 迎撃対象がなければ小型敵を掃射する。

### 5.6 魚雷管制室

役割:

- ボスや大型艦に強い一撃を与える。
- 横から来る敵群をまとめて処理する。
- 機雷で後続敵を減らす。

操作:

- 方向指定: 左、右、前方、斜め前。
- 魚雷発射ボタン: 指定方向へ高威力の魚雷。
- 機雷投下ボタン: 後方または側面に機雷を設置。
- ソナーPingボタン: 一定時間、隠れ敵と弱点を表示。

破損時:

- 魚雷発射不可。
- ソナーが使えないため、隠れ敵やボス弱点が見えづらい。

AI操作:

- ボス、大型敵、密集敵に魚雷を使う。
- 機雷は横湧きが多い時に使う。

## 6. 座席移動仕様

### 6.1 基本ルール

- 左側の戦艦UIから席をタップして移動する。
- 移動には0.5秒の短い移動時間がある。
- 移動中は現在席の操作ができない。
- 壊れている席には移動できない。
- 自分が座っている席が壊れた場合、移動ボタンがロックされ、修理ボタンのみ有効になる。

### 6.2 オンライン時の座席占有

- 1席に座れるプレイヤーは1人だけ。
- 他プレイヤーが座っている席は占有表示。
- 占有席をタップしても移動できない。
- 空席またはAI席には移動できる。
- 移動リクエストはサーバー側で先着判定する。
- 同時に同じ席へ移動した場合、先にサーバーへ届いたプレイヤーが着席する。

### 6.3 ソロ時の座席占有

- 全席に自由に移動可能。
- プレイヤーがいない席はAIが担当。
- プレイヤーが離れた席のクールダウンや装填状態は維持される。

## 7. AI自動操作

### 7.1 AIの目的

プレイヤーが不足していてもゲームが成立するようにする。ただし、プレイヤー操作より少し弱くし、マルチで席を担当する価値を残す。

### 7.2 AIレベル

- 通常AI: 空席を担当。人間の70%程度の効率。
- 修理AI: 空席が壊れた場合に低速で修理。人間連打の40%程度。
- 緊急AI: 戦艦HPが低い時、防衛と修理を優先する。

### 7.3 AIの行動優先度

1. 自席が破損しているなら修理。
2. 戦艦に直撃しそうなミサイルや魚雷を迎撃。
3. ボス弱点を攻撃。
4. 近い敵を攻撃。
5. クールダウン中は冷却や装填。
6. 敵がいない時は次の湧き方向へ準備。

## 8. 戦艦HPと部位破損

### 8.1 HP構造

戦艦は2種類のHPを持つ。

- 戦艦全体HP: 0になるとゲーム終了。
- 部位HP: 各座席や武装ごとのHP。0になるとその部位が破損する。

### 8.2 部位一覧

| 部位 | 対応席 | 破損時の影響 |
|---|---|---|
| 艦橋 | 艦橋 | 移動不能、緊急回避不能 |
| 左主砲塔 | 左主砲 | 左主砲使用不可 |
| 右主砲塔 | 右主砲 | 右主砲使用不可 |
| 左副砲区画 | 左副砲 | 左副砲使用不可 |
| 右副砲区画 | 右副砲 | 右副砲使用不可 |
| 前左防空区 | 前左機銃 | 前左迎撃不可 |
| 前右防空区 | 前右機銃 | 前右迎撃不可 |
| 後左防空区 | 後左機銃 | 後左迎撃不可、煙幕弱体 |
| 後右防空区 | 後右機銃 | 後右迎撃不可、煙幕弱体 |
| 魚雷室 | 魚雷管制室 | 魚雷、機雷、ソナー使用不可 |

### 8.3 被弾処理

- 敵弾が戦艦に当たると、命中位置に近い部位へ部位ダメージを与える。
- 同時に戦艦全体HPにもダメージを与える。
- 部位HPが0になると破損状態になる。
- 破損中の部位にさらに被弾すると、戦艦全体HPへのダメージが増える。

### 8.4 破損状態

破損時の共通仕様:

- 対応する席の操作ボタンが修理ボタンに置き換わる。
- 対応席に座っているプレイヤーは移動できない。
- 対応席に誰もいない場合はAIが低速修理する。
- 他席のプレイヤーは直接その席へ移動できないが、強化によって遠隔修理が可能になる場合がある。

### 8.5 修理操作

- 破損席のプレイヤーは修理ボタンを連打する。
- 1タップごとに修理ゲージが少し増える。
- 一定量まで修理すると部位HPが30%で復旧する。
- 100%まで直すには追加連打が必要。
- 修理中も戦艦全体HPは減り続けるため、緊張感を出す。

修理段階:

| 段階 | 必要ゲージ | 状態 |
|---|---:|---|
| 応急復旧 | 35% | 操作が再開し、移動可能になる |
| 通常復旧 | 70% | 性能低下が消える |
| 完全修理 | 100% | 部位HPが最大まで回復 |

## 9. 敵仕様

### 9.1 敵出現方向

- 前方: 基本の敵。進行方向から現れる。
- 左側: 側面攻撃。左主砲、左副砲、左機銃の価値を高める。
- 右側: 側面攻撃。右側席の価値を高める。
- 斜め前: 回避と迎撃が必要な圧力。
- 後方寄り側面: 機雷や後部機銃が活躍する。

### 9.2 敵種

| 敵名 | 役割 | 特徴 |
|---|---|---|
| 偵察艇 | 基本雑魚 | 低HP、まっすぐ接近 |
| 高速艇 | 横湧き敵 | 速い、体当たり狙い |
| 装甲艇 | 中型敵 | HPが高い、主砲向き |
| ミサイル艇 | 遠距離敵 | ミサイルを撃つ、機銃で迎撃可能 |
| 魚雷艇 | 側面圧力 | 横から魚雷を流す |
| ドローン群 | 防空対象 | 小さく数が多い |
| 機雷散布艇 | 地形妨害 | 進行ルートに機雷を置く |
| 修理艦 | 支援敵 | 他の敵を回復する |
| 電磁艇 | 妨害敵 | 一部の操作UIを短時間乱す |
| ステルス艇 | ソナー対象 | 魚雷席のソナーで見えやすくなる |
| 重巡洋艦 | 大型敵 | 複数部位を持つ |
| 航空母艦 | 敵増援 | ドローンや爆撃機を出す |

### 9.3 敵スケーリング

敵の強さは海域レベルで上がる。

海域レベル:

```text
海域レベル = 1 + floor(進行距離m / 500) + floor(経過秒 / 90)
```

補正:

- 敵HP: 基礎HP * (1 + 海域レベル * 0.12)
- 敵攻撃力: 基礎攻撃力 * (1 + 海域レベル * 0.08)
- 敵出現数: 基礎数 + floor(海域レベル / 3)
- 横湧き率: 20% + min(35%, 海域レベル * 1.5%)
- 特殊敵率: 5% + min(30%, 海域レベル * 1%)

## 10. ボス仕様

### 10.1 出現タイミング

- 初回ボス: 開始から180秒後。
- 以降: 180秒ごとにボス出現。
- ボス中も通常敵は弱めに出現する。
- ボス撃破後は15秒の回収時間が入り、強化選択へ移行する。

### 10.2 ボスの基本ルール

- ボスは複数部位を持つ。
- 弱点部位が周期的に変わる。
- 弱点を攻撃すると大ダメージ。
- 一定HP以下で攻撃パターンが強化される。
- 時間がかかるほど通常敵が増え、戦艦が追い込まれる。

### 10.3 ボス候補

| ボス名 | 特徴 | 対策 |
|---|---|---|
| 重装甲旗艦アトラス | 正面装甲が硬い | 側面砲撃と魚雷 |
| 双胴強襲艦ヘルム | 左右から挟み込む | 艦橋回避と両舷火力 |
| 空母ネスト | ドローンを大量展開 | 機銃と副砲 |
| 潜航破壊艦モルガン | 突然浮上して魚雷 | ソナーと機雷 |
| 電磁要塞艦オラクル | 操作妨害とEMP | 部位修理と防御強化 |
| 砲撃列車艦グラインド | 横一直線の砲撃 | 艦橋の位置取り |
| 廃棄戦艦リヴァイア | 破損部位を狙う | 修理速度と全体防御 |

### 10.4 ボス撃破報酬

- ボス撃破でサルベージカプセルが出現。
- 自動回収または戦艦が近づくことで回収。
- ランダム5つの強化候補が表示される。
- 1つ選ぶと即座に戦艦へ反映される。

### 10.5 マルチでの強化選択

- 全プレイヤーに同じ5択が表示される。
- 10秒以内に投票する。
- 最多票の強化を獲得。
- 同票の場合は艦橋席のプレイヤーの票を優先。
- 艦橋がAIまたは未投票の場合はランダムで決定。

## 12. スコアとお金

### 12.1 基本方針

- スコアは上がりにくくする。
- スコアはそのまま持ち帰り通貨になる。
- 長く生き残るほど効率が上がるが、リスクも大きくなる。

### 12.2 スコア獲得

| 行動 | スコア |
|---|---:|
| 100m進行 | +1 |
| 小型敵撃破 | +1 |
| 中型敵撃破 | +3 |
| 大型敵撃破 | +8 |
| ミサイル/魚雷迎撃 | +1 |
| ボス撃破 | +50 |
| 部位を完全修理 | +2 |
| 海域レベル更新 | +5 |

### 12.3 持ち帰り

- ゲーム終了時、最終スコアと同額のお金を獲得。
- 例: スコア1240なら、お金1240を獲得。
- 回線落ちや途中離脱時は、その時点のチームスコアから個人貢献分を算出して付与する。

### 12.4 スコア倍率

倍率は強くしすぎない。

- ボス連続撃破: 最大 +20%
- 無破損継続: 最大 +10%
- 高海域危険度: 最大 +30%
- 強化による倍率: 原則 +5-15%

### 13.4 持ち込み枠

- 1回の出撃に持ち込める強化はチーム全体で最大10個。
- ソロは1人で10個。
- マルチは参加人数に応じて分配する。

### 13.5 持ち込み分配ルール

参加人数を `N` とする。

```text
基本枠 = floor(10 / N)
余り枠 = 10 % N
```

- 全員が基本枠を持つ。
- 余り枠はルーム入室順または即開始のマッチング順に1枠ずつ配る。
- ただし、連続で同じ人が余り枠を取り続けないよう、アカウントごとに優先権をローテーションする。
- プレイヤーが枠を使い切らない場合、未使用枠はチーム共有枠になる。
- チーム共有枠はロビーで投票、またはおすすめ自動選択で埋める。

## 24. 仕様の要点

- 10席の役割が明確で、どの席でも操作する意味がある。
- ソロでもAIが補助して全席が機能する。
- マルチでは席が埋まり、座席移動と役割分担が遊びになる。
- 無限進行、敵強化、定期ボス、5択強化でローグライト性を作る。
- 部位破損と修理連打で、ただ撃つだけではない緊急対応を作る。
- スコアは上がりにくくし、そのままお金として持ち帰る。
- ガチャと持ち込み10枠で、出撃前のビルド作りを楽しませる。
- スマホ縦画面で、上HUD、左戦艦UI、右プレイ画面を基本にする。
