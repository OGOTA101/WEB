# Core Block Arena 仕様書

## 1. コンセプト

Core Block Arena は、巨大な四角いフィールド上で、ブロックで構成された自機を移動させながら射撃し、敵MOBを倒してブロックを獲得し、自機を大きく強く育てていくトップダウン型ブロック破壊アリーナゲームである。

画面の基本印象は diep.io のような見下ろし型アリーナで、操作は「移動」と「射撃」を中心にする。自機は9つのブロックから始まり、中央のコアブロックが初期武装を持つ。コアブロックがすべて破壊されると敗北する。

## 2. 対応プレイモード

- ソロプレイ: Firebase設定なしでも即時プレイできる。
- オンライン協力/対戦: Firebase Realtime Database 設定がある場合、部屋コードでルームを作成・参加できる。
- 最大同時人数: 7人。
- フレンドリーファイア: 部屋作成時にあり/なしを選択できる設計。
- 協力プレイ: フレンドリーファイアなしで同じフィールドに入り、敵MOBへ共同対処する。

現バージョンでは、ソロは完全に遊べる。オンラインはFirebase接続、部屋作成、参加、ホスト状態公開の土台を実装済みで、今後の完全同期に拡張できる。

## 3. ゲーム開始状態

- 自機は3x3、合計9ブロックで開始する。
- 全ブロックは木材。
- 中央ブロックのみコアブロック。
- 初期コア武装は「前方コア」。
- 初期コアは、自機が進行している方向、または最後に進んだ方向に弾丸を撃つ。
- 初期状態では進行方向にしか撃てない。

## 4. フィールド

- 巨大な四角い板状フィールド。
- フィールド外周は明確な境界線を持つ。
- 自機は基本的にフィールド内へ制限される。
- 敵はノックバックやシールド押し出しにより場外へ出されると撃破扱いになる。

## 5. ブロック

### 5.1 素材とHP

ブロック素材は以下の順番で強くなる。木材をHP1として、以降1ずつHPが上がる。

| 素材 | HP |
| --- | ---: |
| 木材 | 1 |
| レンガ | 2 |
| 石 | 3 |
| 鉄 | 4 |
| ダイヤ | 5 |
| 黒曜石 | 6 |

### 5.2 破壊

- 弾丸の基本威力は1。
- 木材ブロックは弾丸1発で破壊される。
- HPが減ったブロックはひび割れで状態が分かる。
- コアブロックもHPを持つ。
- 自機のコアブロックがすべてなくなるとゲームオーバー。
- コアブロックが複数ある場合、1個破壊されても他のコアが残っていれば継続する。

## 6. ドロップと自機拡張

- 敵MOBを倒すと一定確率でブロックをドロップする。
- ドロップ素材はゲーム時間と敵Tierに応じて強くなる。
- まれに武装付きコアブロックがドロップする。
- ドロップに接触すると自機に吸収される。
- 取り付け位置は、接触位置に一番近い空きマスを優先する。
- 同距離の場合は中心から近い空きマスを優先する。
- つまり、自機の欠けた場所や近い隙間へ自然にはまる。
- 自機が大きくなるほどカメラが引く。塊魂のように成長感を出す。

## 7. 武装コア

射撃ボタンで撃つ手動武装は、ボタン入力時に同じタイミングで一斉発射される。自動武装は個別クールダウンで自動発射される。

実装済み武装:

- 前方コア: 進行方向へ通常弾。
- 自動砲台: 近い敵へ自動発射。
- 誘導弾: 敵方向へ曲がる弾。
- 後方砲: 進行方向の逆へ発射。
- 固定北/東/南/西: 固定方向へ自動射撃。
- 爆弾設置: 低速弾が短時間後に範囲爆発。
- 修復: 低頻度で傷ついたブロックを1回復。
- 強化: 低頻度でブロック素材を1段階強化。
- 鈍足弾: 命中した敵を一定時間遅くする。
- 旋回珠: 自機周囲を回る弾を生成。
- 散弾: 扇状に複数弾を発射。
- ロケット: 遅めで強いノックバック。
- ビーム: 短命だが高速で貫通。
- 狙撃: 高速・長射程。
- 押出弾: ダメージより弾き飛ばしに特化。
- シールド: 自機前方に物理押し出し用シールドを展開。

## 8. 敵MOB

- 時間経過で敵が生成され続ける。
- 基本的には、初期敵を倒したあとに次の敵が補充される。
- 敵は常時タイマーで大量増殖せず、撃破テンポに合わせて増える。
- 敵MOBも丸いキャラクターではなく、プレイヤーと同じく四角いブロック集合として表現する。
- 最小の敵はコアブロック1個のみの構成でもよい。
- 経過時間に応じてTierが上がり、ブロック数、HP、速度、サイズが増える。
- 敵は自機へ接近する。
- 接触すると自機ブロックへ1ダメージ。
- 敵のコアブロックが破壊されると敵は撃破扱いになる。
- ノックバックで場外へ出すことでも倒せる。
- 敵の移動AIは単純な直進だけでなく、直進、横移動、周回、突進、回り込み、距離取りの複数パターンを持つ。

## 8.1 ブロック接続ルール

- ブロック同士の接続は上下左右の辺接続で判定する。
- コアブロックに接続していない非コアブロックは、切断されたものとして破壊される。
- 複数コアがある場合、いずれかのコアに接続しているブロックだけが生存する。
- コア同士が離れていても、それぞれのコアを中心に別の接続群として維持できる。

## 9. 弾丸

- 通常弾の基本威力は1。
- 弾種ごとに速度、寿命、半径、貫通、ノックバック、鈍足効果が異なる。
- 弾丸タイプ:
  - 通常弾
  - 誘導弾
  - 爆弾
  - 鈍足弾
  - ロケット
  - ビーム
  - 狙撃弾
  - 押出弾
  - 旋回弾

## 10. 操作

### PC

- WASD / 矢印キー: 移動。
- Space / 画面クリック: 射撃。

### モバイル

- 左下の移動パッド: アナログ移動。
- 右下の射撃ボタン: 手動武装を一斉発射。

## 11. UI

- タイトル画面。
- ソロ開始。
- 部屋作成。
- 部屋参加。
- フレンドリーファイア切替。
- ハイスコアランキング。
- プレイ中HUD:
  - スコア
  - 経過時間
  - ブロック数
  - コア数
  - 所持武装一覧

## 12. スコア

- 敵撃破で加点。
- 場外撃破も加点。
- ブロック取得で加点。
- コア取得は通常ブロックより高得点。
- ローカルランキングに上位10件を保存する。

## 13. ビジュアル

- ドット絵風。
- ブロック、敵、弾丸、ドロップはピクセルアート調で統一。
- 背景には素材画像を敷かず、巨大な四角い板とグリッドだけで視認性を優先する。
- 生成画像アセットは参照素材・追加弾丸素材として保持し、ゲーム背景には使用しない。
- ゲーム内のブロック、コア、弾丸、ドロップは、視認性を優先してPhaser Graphicsでトップダウンのピクセル素材として描画する。
- ドロップブロックは少し小さく、発光し、素材・HP・武装が一目で分かるラベルを持つ。

## 13.1 サウンド

- 射撃、命中、破壊、ドロップ、取得、ゲームオーバーに簡易SEを付ける。
- SEはブラウザの自動再生制限に合わせ、最初のキー入力またはポインター入力後に有効化する。

## 14. Firebase

- Firebase Hostingで静的配信する。
- `public/firebase-config.json` が存在する場合、Realtime Database連携を有効化する。
- `public/firebase-config.example.json` をコピーして実プロジェクト値へ置き換える。
- Hostingは `dist` を公開する。
- 部屋情報は `rooms/{roomCode}` 配下に保存する設計。
- 1部屋の最大人数は7人。
