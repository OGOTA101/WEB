# 実装反映チェック

## 今回確認した未反映・ズレ

| 項目 | 状態 | 対応 |
| --- | --- | --- |
| 敵MOBが四角いブロックで構成される | 未反映 | 円形MOBを廃止し、敵もコアブロックを含むブロック集合に変更 |
| 敵がプレイヤーと同じ見た目で巨大化する | 一部未反映 | Tierに応じて1ブロックから複数ブロック構成へ拡張 |
| 切断された非コアブロックが死ぬ | 未反映 | コアから上下左右で接続していない非コアブロックを自動破壊 |
| カメラがもっと引く | 不足 | ブロック数と広がりに応じてより強くズームアウト |
| 素材が上面視ドット絵として見える | 不足 | 素材ごとに平面パターンを追加し、斜め表現を排除 |
| 生成画像の斜め感 | 不適合 | 上面視のみの新しい生成画像へ差し替え、ゲーム内では控えめな背景素材として使用 |
| 背景に素材画像が敷かれている | 不適合 | ゲーム背景とタイトル背景から素材画像を外し、グリッド背景のみに変更 |
| 弾丸が丸い | 不適合 | 弾丸種別ごとに四角・三角・線分ベースのピクセル素材表現へ変更 |
| ドロップコアが丸い | 不適合 | 小さめの発光ブロック表示に変更し、素材・HP・コア武装ラベルを表示 |
| 簡易SE | 未実装 | Web Audioの簡易SEを射撃、命中、破壊、ドロップ、取得、敗北へ追加 |
| 敵が時間で増えすぎる | 不適合 | 常時タイマー湧きを止め、撃破後に次の敵が補充される方式へ変更 |
| 敵移動が単純 | 不足 | 直進、横移動、周回、突進、回り込み、距離取りの6パターンを追加 |
| 弾丸素材感が弱い | 不足 | 種別ごとに黒縁・発光・四角/三角/線分のピクセル素材表現を強化 |

## 仕様書上で明文化が足りなかった点

- 敵MOBも丸いキャラではなく、プレイヤーと同じくブロック集合として扱う。
- 敵の最小形はコアブロック1個で、時間経過・Tier上昇により巨大化する。
- ブロックの接続判定は上下左右の辺接続を基本にする。
- コアに接続していない非コアブロックは、破壊されたものとして即時除去する。
- 複数コアがある場合は、どれかのコアに接続しているブロックだけが生存する。
- 素材表現は完全なトップダウン表示で、斜め・アイソメ・立体影を使わない。

## まだプロトタイプ段階の項目

- オンラインは最大7人の部屋作成、参加、位置・ブロック共有までは実装済み。ただし、敵や弾丸の完全な権威サーバー同期はまだ簡易。
- フレンドリーファイアの設定UIは実装済み。ただし、オンライン全員の弾丸当たり判定を統一する段階で最終反映が必要。
- 武装の種類は一通り入っているが、各武装のバランス、演出、敵コアからの武装継承の細部は調整余地あり。
