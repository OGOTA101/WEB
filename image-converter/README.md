# Image Drop Converter

Explorerから画像ファイルやフォルダをドロップして、JPG・PNG・BMPへ一括変換するWindows用の小さなアプリです。

## 使い方

1. `dist\ImageDropConverter.exe` を起動します。
2. 出力形式を `JPG` / `PNG` / `BMP` から選びます。
3. 初期状態の `キューを使わない（即時変換）` がONなら、Explorerからファイルまたはフォルダを画面へドロップするたびに、その分だけ自動変換します。変換中でも次のファイルを続けてドロップできます。
4. `容量を減らす`、`ダウンロードフォルダへ保存` も必要に応じてONにします。
5. まとめて登録してから変換したい場合だけ、`キューを使わない（即時変換）` をOFFにします。OFFではドロップしたファイルがキューに入り、`変換を開始` で処理します。

初期状態では、各画像の元フォルダへ保存します。元画像は上書きせず、同名ファイルがある場合は `_converted` や連番を付けます。

## 動作仕様

- 最大999件。999件を超えた分は対象外にして処理を続けます。
- 即時変換ONでは常設キューを使わず、ドロップ単位で変換します。通常キューの変換完了後も、完了済みのファイルは自動的に消費されます。
- 拡張子で絞り込まず、Pillowで開けるかを試します。対応外・破損・アクセス不可のファイルは静かに `SKIP` し、残りを最後まで処理します。
- PNGは透過を保持します。JPGとBMPは形式上透過を保持できないため、白背景へ合成して保存します。
- 容量削減ONでは、JPEGの品質を下げ、PNGの圧縮とメタデータ削減を強めます。BMPは形式の制約上、容量が大きく変わらない場合があります。
- GIFやTIFFなどの複数フレーム画像は先頭フレームを変換します。
- ログは実行ファイルと同じフォルダの `conversion.log` に保存します。書き込みできない場所では `%LOCALAPPDATA%\ImageDropConverter\conversion.log` を使います。

## 開発・再ビルド

```powershell
python -m pip install -r requirements.txt
.\build.ps1
```

生成物は `dist\ImageDropConverter.exe` です。
