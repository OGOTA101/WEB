# Deploy Cat Catch

This workflow deploys the Cat Catch game to Firebase Hosting.

## Steps

1. Navigate to the cat-catch directory:
```
cd c:\Users\ihogo\Desktop\WEB\cat-catch
```

2. Deploy to Firebase:
```
firebase deploy --only hosting:cat-catch
```

3. After deployment, update the HP site to add a link to the new game (if not already done).
