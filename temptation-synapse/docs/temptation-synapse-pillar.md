# 誘惑のシナプス - Pillar Contract

## Intent

- 女の子の脳内にある空腹信号から食欲中枢までを、一筆書きでつなぐ。
- 高カロリーパネルを拾いながら、短絡・野菜・運動の誘惑を避ける。
- 1週間を1面として10週間を駆け抜け、正解するたびに身体の変化が積み上がる。
- 1面あたり数十秒で遊べて、失敗理由がその場で分かる。
- アイコンと文字だけでルールと状況が読める。

## Core Fun

近道を選べば理性が勝ち、遠回りして誘惑を拾えば身体が変わる。次の一手を迷う小さな緊張と、正解後に毎週少しずつ太っていく実感を主役にする。

## Pillars

### one-stroke-routing

空腹信号から食欲中枢まで、隣り合うシナプスを一筆書きで進む。通過済みのパネルには戻れず、ゴール時にルート全体を判定する。

### temptation-vs-reason

🍔高カロリーを規定数以上集め、最低歩数以上の遠回りをすると正解。🥗野菜・🏋️運動を踏む、短すぎる、または摂取量不足なら失敗になる。

### ten-week-body-arc

正解ごとに体重・お腹まわり・満腹度が上がり、週のメッセージも変化する。失敗時は同じ週をすぐやり直せる。

### quick-readable-feedback

盤面の凡例、現在ルート、摂取カロリー、歩数、正解条件を常に見せる。成功・失敗時には「なぜそうなったか」と身体変化を一画面で返す。

## Core Loop

- 今週の脳内盤面を読む。
- 現在のノードに隣接するパネルをタップする。
- 高カロリーかダイエットかを見ながら遠回りを続ける。
- 食欲中枢に到達したらルート条件を判定する。
- 成功なら身体変化を記録して次週へ、失敗なら同じ週をやり直す。

## Art Direction

依存なしのHTML/CSS/SVGによる2Dブラウザプロトタイプ。濃紺の脳内ネットワークを背景に、食欲はコーラル、ダイエットはミント、現在の神経ルートはクリーム色で表現する。画像生成や外部アセットは使わず、絵文字・記号・文字とCSSの発光だけで成立させる。

## Modules

### level-data

- Carries: 10週間分の盤面、正解ルート、食べ物・ダイエット配置、必要歩数とカロリー条件。
- Watch-out: 盤面を追加するときは、正解ルートがスタートからゴールまで連結し、ダイエットパネルを踏まないことを確認する。

### route-board

- Carries: 隣接ノード選択、一筆書きの履歴、SVGの経路表示、戻る・リセット・ヒント操作。
- Watch-out: タッチ操作でも誤タップを起こしにくい大きさを保ち、再訪・斜め移動・ブロック通過を許可しない。

### week-progression

- Carries: 成否判定、10週間の進行、体重・部位・満腹度の更新、週メッセージ。
- Watch-out: 正解時の増加は毎週必ず発生させ、失敗時に次週へ進めて成功体験を薄めない。

### feedback-hud

- Carries: 凡例、条件メーター、脳内ログ、結果カード、最初から・次週・再挑戦。
- Watch-out: 盤面の操作領域を圧迫せず、失敗理由を抽象語だけで終わらせない。
