# 誘惑のシナプス

脳内の神経回路を一筆書きでつなぐ、10週間のアイコン・パズルゲームです。

## 起動

画像や外部ライブラリを使っていないので、`index.html` をブラウザで開くだけで遊べます。

ローカルサーバーで確認する場合は、プロジェクトフォルダで次を実行します。

```powershell
python -m http.server 5173
```

その後、`http://127.0.0.1:5173/` を開いてください。

## ルール

- `◉ 空腹信号` から開始し、上下左右に隣接したパネルだけを選びます。
- 一度通ったパネルには戻れません。
- `🍔` の高カロリーパネルを規定数以上通ります。
- `🥗` / `🏋️` のダイエットパネルは0個にします。
- 最低歩数以上の遠回りで `◎ 食欲中枢` に着くと、その週は成功です。
- 成功した週は体重・お腹まわり・満腹度が増え、次の週へ進みます。

`💡 ヒント` はその週の正解ルートの最初の一手を点灯します。失敗した週は同じ週をすぐにやり直せます。
