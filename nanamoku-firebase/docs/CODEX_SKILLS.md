# Codexスキル導入メモ

## 今回使ったスキル

| スキル | 用途 |
| --- | --- |
| game-studio | ブラウザゲーム全体の設計方針 |
| web-game-foundations | ルール、描画、UI、通信の分離方針 |
| skill-installer | 必要そうな追加スキルの確認と導入 |

## 既に利用できる関連スキル

| スキル | 用途 |
| --- | --- |
| frontend-design | UIを綺麗に作る |
| webapp-testing | ローカルWebアプリをPlaywrightで検証する |
| browser-use | in-app browserで画面を開いて確認する |
| Systematic Debugging | エラー調査時にログから原因を特定する |
| HTML Audio Manager | 効果音やBGMを入れる時に使う |

## 追加インストールしたスキル

| スキル | 理由 |
| --- | --- |
| playwright | 実装後のブラウザ操作テストに使う |
| security-best-practices | Firestore RulesとFunctions設計の安全確認に使う |

追加スキルはCodexを再起動すると拾われる。

## 見つからなかったもの

Firebase専用の curated skill は一覧に見当たらなかった。Firebase部分は公式SDKの実装方針に沿って、プロジェクト内の設計資料と実装で固める。
